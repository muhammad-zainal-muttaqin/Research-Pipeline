\section{Derived metrics and decision rules}
\label{app:rules}
\subsection{Paired bootstrap}
For a contrast between arms \(a\) and \(b\), images are grouped by physical
tree before resampling. Each bootstrap replicate samples trees with
replacement, evaluates both arms on the same sampled trees, and stores the
difference \(m_a-m_b\). The reported interval is the percentile 95\% interval
over 2,000 replicates. This pairing removes shared tree difficulty but does
not remove seed-specific optimization variance.

\subsection{Bottleneck decomposition}
The intended E-014 diagnostic holds the prediction list and ground truth fixed
while scoring four-class and class-agnostic labels. The current implementation
must verify that invariant at the exported JSON level; two separate
``model.val'' calls can otherwise change NMS. Until that check is present, the
difference is a bottleneck diagnostic rather than a causal decomposition of
all feature computation inside the network.

\subsection{Cross-side consistency}
For a physical bunch \(u\), let \(C_u\) be the set of predicted classes over
appearances with at least two matched detections. The inconsistency indicator
is \(I_u=1\) when \(|C_u|>1\). A separate missed-appearance rate counts
appearances without a matched detection. The denominator for inconsistency is
therefore measured bunches, not all physically present bunches.

\subsection{Phase A: establish what can be measured before adding a sensor}
The first branch is intentionally unglamorous. Before a fourth channel can
be credited for separating an occluded bunch, the repository must know what a
``bunch'' means, whether labels belong to the image being trained, and whether
multi-view geometry contributes information that RGB does not already contain.
E-001 and E-002 therefore test the measurement and provenance contracts before
any representation is changed. E-003--E-005 then use relative geometry only as
a tree-level feasibility probe. They are not depth-detector experiments.

The phase ends with a deliberately hard handoff. E-006 tests local separation
against size-matched random controls, and E-007 tests whether a geometric rule
can count one physical bunch across views. If either mechanism had survived,
the next branch could have used it to define an identity-aware RGB-D target.
Instead, the evidence moves the burden upstream: use a physical sensor for a
new modality, and diagnose the RGB detector itself before interpreting any
depth delta. E-008 is kept as a visible reservation so that the chronology has
no invented null.
