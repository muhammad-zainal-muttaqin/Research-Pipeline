KEY: suharjito2025oil (Suharjito et al., Scientific Data 12:972, 2025; doi 10.1038/s41597-025-05227-x; accepted 19 May 2025)

CROP / SETTING / SCALE: Oil palm fresh fruit bunches (FFB) on unharvested trees 1-3 m tall in commercial plantations, Central Kalimantan, Indonesia; collected 2023. Dataset descriptor, not a counting method. 440 videos, 8 s to 1 min 31 s.

ACQUISITION: Smartphone video, 30 fps, 320 x 640 px, portrait, MP4. The operator recorded "by rotating around each tree" (Methods) and "circling each tree to capture all visible FFB" (Data Records). Camera height, distance from tree, and number of passes per tree: not stated. Frames extracted frame by frame and annotated in CVAT. Number of frames extracted per video: not stated.

OBSERVATION / DETECTOR: Bounding-box object detection on single frames; boxes drawn on fruit and oil palm flowers. Five classes: Unripe, Underripe, Ripe, Flower, Abnormal. Detectors: YOLOv8n and YOLOv8s (Ultralytics; version not stated). Input 640 x 640, 3 channels. Each frame is annotated independently; no identity is assigned to a fruit across frames. Detection accuracy as reported: see KEY QUANTITATIVE RESULTS.

ASSOCIATION METHOD: None. Single-frame detection. No tracker, no motion model, no appearance matching, no 3D/SfM/SLAM, no counting line or unique-ID rule. No count procedure is described or evaluated.

ASSUMPTIONS STATED OR IMPLIED BY AUTHORS:
- Recording around the tree captures "all visible FFB" (Data Records).
- Augmentation and over/under-sampling equalise the number of objects across classes (Methods). Unripe and Abnormal nonetheless remain the largest and smallest classes (Technical Validation, Table 2).
- The 1-3 m tree height range is the scope of the dataset (Usage Notes).
- Expert labelling defines ripeness correctly (Methods describes an expert defining ripeness levels). No inter-annotator agreement is reported.
- Augmented images are treated as independent samples in the splits (implied by Table 2 counts; not stated explicitly).

DOUBLE-COUNT SOURCES ADDRESSED:
(a) Same fruit in consecutive frames: not addressed. 30 fps video frames are annotated and split as images; no deduplication or frame subsampling is described.
(b) Track lost and restarted: not applicable; no tracking.
(c) Same fruit from both sides or different passes: not addressed. Circling the tree is described only as a way to capture "all visible FFB"; no cross-view linking is described.
Split unit (video, tree, or frame) is not stated. Frames from the same video and augmented copies of the same frame appear in the dataset, so leakage across the 70/20/10 split cannot be excluded from the text. Whether augmented copies were removed from the test set is not stated.

CLASS / MATURITY HANDLING: Five classes assigned per bounding box per frame: Unripe, Underripe, Ripe, Flower, Abnormal. Class is attached to each box in each frame; no rule for a unique fruit or for frames that disagree. Post-augmentation counts (Table 2, train/val/test): Unripe 4990/1699/764; Ripe 2354/443/192; Underripe 1324/298/181; Flower 1121/251/182; Abnormal 418/205/81. Text attributes the Unripe majority to ripe fruit being harvested first.

COUNT REFERENCE AND METRIC LEVEL: No count reference (no hand count on tree, harvest, or packhouse count). No count error, no MOTA/IDF1/HOTA, no ID switches. Metrics are detection only: mAP_0.5 and mAP_0.5:0.95. The split on which Table 5 values were computed is not labelled (see INCONSISTENCIES).

KEY QUANTITATIVE RESULTS (as reported):
- Table 5 (p.6), YOLOv8n vs YOLOv8s:
  - mAP_0.5: 0.735 vs 0.745
  - mAP_0.5:0.95: 0.480 vs 0.480
  - Precision: 0.725 vs 0.738
  - Recall: 0.711 vs 0.719
  - F1: 0.718 vs 0.728
  - FPS: 90 vs 36
  - GPU memory: 9.6 GB vs 4.5 GB
  - Model size: 6 MB vs 21 MB
- Text (p.5): YOLOv8n precision 0.725 and recall 0.711 are given for the final epoch.
- Text (p.5): YOLOv8s stopped automatically at epoch 87 because there was no visible improvement for 50 epochs.
- Table 3 (p.5), YOLOv8s only, ablation: without augmentation mAP_0.5 71.9 and mAP_0.5:0.95 47.1; with augmentation 74.5 and 48.0 (values in percent). Single configuration (seed 10, Table 4); no variance reported.
- Table 4: maximum 100 epochs; batch 64 (YOLOv8n) and 16 (YOLOv8s); input 640 x 640; learning rate 0.01; SGD; momentum 0.9; seed 10.
- Table 1: prior FFB datasets listed with class counts; a descriptor comparison, not a result.
- Fig. 7 mobile prototype: response times "measured ... in milliseconds" (no number given).

FAILURE CONDITIONS / ERROR SOURCES REPORTED:
- Partial visibility, low contrast, occlusion, and blurriness (dataset challenges, p.4).
- Class imbalance: Unripe is the largest class and Abnormal the smallest (p.4-5).
- YOLOv8s validation losses described as erratic (p.5).
- mAP_0.5:0.95 is the same for both models despite the higher precision of YOLOv8s (p.5).
- Smartphone resolution limits (Usage Notes).
- Trees of 1-3 m only (Usage Notes).

COMPARISONS ON THE SAME DATA: YOLOv8n vs YOLOv8s on this dataset, and YOLOv8s with vs without augmentation. No comparison with other detectors or with prior datasets on the same images. Table 1 compares dataset descriptors, not performance.

AUTHORS' STATED LIMITATIONS / FUTURE WORK:
- Trees of 1-3 m only; the dataset "does not represent every image of oil palm FFB in plantations that have tree heights above it" (Usage Notes).
- Smartphone resolution limits (Usage Notes).
- Class imbalance and the risk of overfitting limit how far augmentation can go (Technical Validation; paraphrase).
- No future-work section.

INCONSISTENCIES INSIDE THE PAPER:
- Table 2 caption reads "Distribution of pre-processing dataset results", while the text says the split came first and augmentation then produced "the distribution shown in Table 2". The Table 2 totals (10,207 / 2,896 / 1,400) are post-augmentation counts.
- Table 1 "Total Images" for this dataset is 14,503, the sum of the per-class object counts (Ripe 2989, Underripe 1803, Unripe 7453, Flower 1554, Abnormal 704). This equals the post-augmentation split total. The number of frames before augmentation is not reported.
- Table 5 caption reads "Training, Validation, and Testing Results", but its columns are not labelled by split.
- Text (p.6-7) calls YOLOv8n "much lightweight" for GPU use. The same passage reports 9.6 GB for YOLOv8n against 4.5 GB for YOLOv8s, and attributes the difference to batch size (Table 4 batch 64 vs 16), not to model size.
- Abstract totals (10,207 / 2,896 / 1,400) match Table 2 and the Data Records text.
