CROP AND DATA: apple and peach (synthetic fruit trees from the public FruitNeRF Dataset); test data: one apple scene with ground-truth count 283 fruit and one peach scene with ground-truth count 152 fruit; also one real soybean plant, 149 retained RGB images extracted at 5 fps from a handheld iPhone 12 Pro video, with single-pod and double-pod mask tasks sharing the same reconstruction. Reference type: annotated fruit count for the synthetic scenes (FruitNeRF dataset annotated by fruit count); no dense 3D ground truth for the field soybean, so its 3D result is assessed qualitatively.
SAME-DATA COMPARISON: yes
C1 TYPE: MECHANISM
C1 ARMS: InvNeRF-Seg (two-stage: train standard NeRF on RGB for 4000 epochs, then fine-tune for 6000 epochs on binary masks formatted as RGB-like inputs with unchanged MSE) vs FruitNeRF with BCE loss (joint RGB + segmentation branch, composite loss RGB + phi*seg, phi = 1) vs FruitNeRF with MSE loss (same joint training, MSE on the segmentation head) vs SA3D density-based (threshold raw NeRF field density sigma >= 70 plus 2D mask filtering) vs SA3D weight-based (back-project 2D masks using volume-rendered weights with threshold tau = 0.1). All arms use the same NeRF configuration per dataset and the same downstream clustering pipeline (DBSCAN eps = 0.0065, min_samples = 3, then recursive KMeans splitting); the arms differ in how multi-view observations are merged into a 3D segmented point cloud that is then counted.
C1 RESULTS: Apple (GT = 283): InvNeRF-Seg 282; FruitNeRF (BCE) 294; FruitNeRF (MSE) 289; SA3D (density) 1573; SA3D (weight) 351. Peach (GT = 152): InvNeRF-Seg 155; FruitNeRF (BCE) 160; FruitNeRF (MSE) 156; SA3D (density) 1249; SA3D (weight) 328. Best on both datasets: InvNeRF-Seg, with the count closest to ground truth.
C1 WHERE: Table 1 (lines 419-438); supporting text in section 4.5.3 (lines 396-398) and section 4.5.2 (lines 379-395).
C1 QUOTE: "Using the identical clustering pipeline across all methods, InvNeRF-Seg achieves the most accurate fruit counts (Table 1)." (lines 397-398)
C1 AUTHORS' EXPLANATION: Cleaner point clouds from InvNeRF-Seg separate naturally into individual fruit clusters, whereas noisier point clouds from the other methods fragment and overcount (lines 399-407). The cause is the refined density field: InvNeRF-Seg fine-tuning suppresses background density and reinforces object density, SA3D uses an unmodified density field, and FruitNeRF joint training compromises density field quality (lines 391-395). The advantage is attributed to the two-stage fine-tuning strategy rather than the loss function, because FruitNeRF with MSE reaches comparable final IoU to FruitNeRF with BCE yet both remain worse (lines 474-482).
C1 CONDITIONS: Synthetic apple and peach trees with default far plane 1000 and no parameter tuning; identical model capacity, training schedule and far-plane values for InvNeRF-Seg and FruitNeRF per dataset; 4000 RGB epochs plus 6000 fine-tuning epochs, with FruitNeRF trained 6000 epochs to match the total budget (lines 298-328). SA3D uses the pretrained RGB NeRF without extra training. Identical DBSCAN parameters for all methods (lines 346-351). Experiments ran on Windows 11 Pro, Intel Core i9 5 GHz x 16 CPU, 64 GB RAM, NVIDIA RTX A5500 16 GB (lines 359-362). Fruit similarity and occlusion conditions for the synthetic counting comparison are not stated.
C2 TYPE: MECHANISM
C2 ARMS: SA3D weight-based, the original variant that back-projects 2D segmentation masks into 3D using volume-rendered weights with threshold tau = 0.1 and produces surface-like point clouds, vs SA3D density-based, which thresholds raw field density sigma >= 70 combined with 2D mask filtering and produces denser volumetric point clouds. Both operate on the pretrained RGB NeRF with no additional training or fine-tuning and both feed the same DBSCAN clustering pipeline.
C2 RESULTS: Apple (GT = 283): SA3D density-based 1573, SA3D weight-based 351. Peach (GT = 152): SA3D density-based 1249, SA3D weight-based 328. Closer to ground truth on both datasets: SA3D weight-based, although both variants overcount heavily; both are worse than InvNeRF-Seg (282 and 155).

The authors then state that InvNeRF-Seg still outperforms both variants, so they attribute the advantage to density field refinement through fine-tuning rather than the point cloud extraction strategy (lines 518-522).
