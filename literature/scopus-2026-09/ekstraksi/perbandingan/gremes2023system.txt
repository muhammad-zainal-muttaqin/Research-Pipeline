  - Boosting: omission 15, wrong 2, double count 10, repeated ID 1, counted 204.
  - CSRT: omission 15, wrong 2, double count 10, repeated ID 1, counted 204.
  - KCF: omission 15, wrong 2, double count 16, repeated ID 1, counted 210.
  - MedianFlow: omission 15, wrong 2, double count 10, repeated ID 1, counted 204.
  - MIL: omission 15, wrong 2, double count 9, repeated ID 1, counted 203.
  - Best arm (closest to 208): Dlib, Boosting, CSRT, MedianFlow (each 204, error -4). No tracker is 215 (+7). Counts and errors in Table 3 are the single run; no variance is reported.
C1 WHERE: Table 3, lines 583-653; text lines 654-668 and 690-698; Conclusions lines 804-808.
C1 QUOTE: "It was also possible to notice that there was no significant difference in the count when different object trackers were used." (lines 690-691)
C1 AUTHORS' EXPLANATION: Trackers only follow an orange for at most 35 frames after YOLOv4 loses it. At 60 fps, the orange looks almost the same over those 35 frames, so all trackers perform alike (lines 691-698). Without a tracker, YOLOv4 misses cause more double counts and repeated IDs, and the tracker reduces double counts (lines 657-668).
C1 CONDITIONS: One 10 s video, one run per arm, 208 true oranges. Differences between trackers are 1 to 7 counts and are not tested statistically. The 204 in the abstract (lines 60-61) and Conclusions (line 806) is the count of the tracker arms, not a single named arm.
