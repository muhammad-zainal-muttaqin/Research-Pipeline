CROP AND DATA: Strawberry (flowers, unripe fruits, ripe fruits), Florida farm, 2017-2018 season. Test data: 236 raw nadir/oblique RGB images (2848 x 4288 px, line 719) used to build one orthomosaic (1 mm GSD, lines 225-227); 4363 Faster R-CNN detections from 456 raw images, corresponding to 1086 unique identities (lines 420-422); Faster R-CNN test set 357 images (Table 1, line 402-403). Reference: hand count by visual interpretation of multi-view raw images (1086 identities; per class 430 flowers, 550 unripe, 106 ripe, Table 5 lines 997-1023) and hand count on the orthomosaic (841 total; 346 / 417 / 78, Table 5 lines 997-1013).
SAME-DATA COMPARISON: yes
C1 TYPE: ACQUISITION (orthomosaic from one nadir-referenced SfM product vs. raw multi-view images); also MECHANISM (orthomosaic detection counted directly vs. per-image detection, projection to ground, then clustering)
C1 ARMS: (a) Benchmark: Faster R-CNN run on the orthomosaic, count = detections on orthomosaic (lines 172-173). (b) Proposed, DBSCAN: Faster R-CNN on each raw image, 3D projection to ground, FaceNet Model-2 embedding, DBSCAN clustering (lines 174-180, 635-637). (c) Proposed, threshold: same as (b) with threshold clustering (lines 560-579). The two proposed arms differ only in clustering algorithm; (b) and (c) are also described as the same pipeline with the same reference.
C1 RESULTS: Overall accuracy (Eq. 18, Table 6, lines 1088-1110), as printed. Flowers: ortho 76.28%, DBSCAN 96.28%, threshold 96.98%. Unripe fruits: ortho 71.64%, DBSCAN 99.09%, threshold 93.64%. Ripe fruits: ortho 69.81%, DBSCAN 97.17%, threshold 97.17%. All: ortho 73.30%, DBSCAN 99.26%, threshold 97.70%. Best arm: DBSCAN on unripe and All; threshold on flowers (96.98 vs 96.28); tie on ripe. Counts (Table 5, lines 997-1023): ortho 328 / 394 / 74 / 796; DBSCAN 414 / 555 / 109 / 1078; threshold 417 / 585 / 109 / 1111. Accuracy values are recomputed from these counts and match Table 6 only if the reference is the raw-image manual count (430 / 550 / 106 / 1086): 1 - |ref - pred| / ref. Occlusion rate (Table 5, line 999 and 1006): flowers 19.53%, unripe 24.18%, ripe 26.42%, all 22.56% (lines 785-790).
C1 WHERE: Table 5 (lines 983-1023), Table 6 (lines 1088-1110), Section 3.2.2 (lines 783-796), Section 5 (lines 975-982).
C1 QUOTE: "The result shows the raw images helped us find 19.53%, 24.18%, and 26.42% more flowers, unripe fruits, and ripe fruits respectively than the orthomosaic image." (lines 975-977)
C1 AUTHORS' EXPLANATION: Occlusion: "Table 6 indicates that occlusion is the key factor preventing the traditional approach from catching up with the proposed approach and Faster R- CNN is not a bottleneck due to its good performance for object detection task." (lines 830-834). Occluded fruit is invisible in the orthomosaic because of pixel merging and blending (lines 804-806). The orthomosaic arm is scored against the raw-image reference (1086), not its own orthomosaic count (841).
C1 CONDITIONS: Single field, one season, one growth stage; the paper states it has not tested mature, crowded plants (lines 945-948). Platform: ground-based vehicle at about 3.5 m height, >70% overlap and >60% sidelap (lines 200-202). Orthomosaic and raw images come from the same 2017-2018 acquisition (lines 182-184); the paper does not say whether the 236 raw images are the same set as the 456 raw images used for the FaceNet dataset (lines 420-421).
NOTES: (1) Abstract (lines 32-35) reports flowers 76.28% to 96.98% (threshold arm), unripe 71.64% to 99.09% (DBSCAN arm), and ripe 69.81% to 97.17%. The abstract mixes the two clustering arms. (2) Section 3.2.2 (lines 781-782) and Section 4.1 (lines 936-937) call DBSCAN "slightly more effective and robust", but Table 6 gives threshold the higher flowers accuracy. (3) Table 6 header prints DBSCAN before threshold; the column assignment was checked by recomputing the accuracy from Table 5 counts. (4) The paper gives 236 raw images (line 719), 456 raw images (line 420), and 2058 + 357 training/test images (Table 1). These are not reconciled in the text. (5) Table 2 (ortho Faster R-CNN, lines 508-552) uses the orthomosaic manual count 841 as reference; Table 6 uses 1086. The text (lines 807-809) cites 73.3% as "the actual number of strawberries on the ground", which is the 1086 reference.

C2 TYPE: MECHANISM (association by clustering rule: threshold on embedding distance vs. DBSCAN density clustering)

C2 RESULTS: Table 4 (lines 885-929), as printed.
