KEY: nuske2014automated
CROP AND DATA: grape (Vitis vinifera; Thompson Seedless, Traminette, Flame Seedless, Chardonnay, Riesling cultivars in the paper). Test data for the arms in C1: 56 Thompson Seedless grape clusters in a laboratory dataset (Table IV, lines 1372-1395). Test data for C2: Traminette vineyard dataset (Table V, lines 1429-1437); number of vines, clusters and images not stated in the lines read. Reference type: manual berry count on clusters (laboratory); for the vineyard, automated berry counts compared with harvest weight (Section 5.5, lines 1467-1500), not with a hand count of the arms in C2.
SAME-DATA COMPARISON: yes

C1 TYPE: MECHANISM
C1 ARMS: four per-image cluster-size models run on the same 56 laboratory clusters. (a) 2D visible berry count, Eq. (4). (b) ellipsoid 3D model, Eq. (6). (c) convex hull 3D model, Eq. (5). (d) total berry count (manual reference). The arms differ in how the per-image measurement is converted to a berry count: a direct visible-berry count versus a volumetric extrapolation from the visible silhouette (ellipsoid or convex hull). Each arm is compared against the total berry count.
C1 RESULTS: Total berry count R2 = 0.95, MSE 9.3%. 2D visible berry count R2 = 0.88, MSE 15.4%. Ellipsoid 3D model R2 = 0.85, MSE 17%. Convex hull 3D model R2 = 0.92, MSE 13.7%. Best on both metrics among the image-based arms: convex hull 3D model (highest R2 and lowest MSE among the three image measurements). The total berry count row is the reference and is not an image arm.
C1 WHERE: Table IV, lines 1372-1395; text lines 1402-1418 and 1437-1445.
C1 QUOTE: "The ellipsoidal model has a correlation score of R2 = 0.88" (lines 1416-1417). Table IV prints 0.85 for the same arm; see NOTES. The convex hull result is stated as: "correlates at R2 = 0.92, which is the best of the three image measurements." (lines 1444-1445)
C1 AUTHORS' EXPLANATION: The ellipsoid model "correlates with a lower score than the visible berry measure" (lines 1437-1442), and the authors give possible reasons there. The authors state the convex hull is best of the three image measurements (lines 1444-1445). Reasons beyond those lines: not stated in the lines read.
C1 CONDITIONS: laboratory setting, 56 Thompson Seedless clusters; images per cluster and frame rate not stated in the lines read; cluster segmentation for the volumetric models is described as working in the laboratory.

C2 TYPE: MECHANISM
C2 ARMS: three per-image cluster-size models run on the same Traminette vineyard images. (a) 2D visible berry count. (b) ellipsoid 3D model. (c) convex hull 3D model. The arms differ in how the per-image measurement is converted to a berry count: visible-berry count versus volumetric extrapolation. No reference count is printed in Table V; the R2 values are the correlation with the reference berry counts as reported by the authors.
C2 RESULTS: 2D visible berry count R2 = 0.75. Ellipsoid 3D model R2 = 0.61. Convex hull 3D model R2 = 0.41. MSE: not stated (Table V prints no MSE). Best on R2: 2D visible berry count.
C2 WHERE: Table V, lines 1429-1437; text lines 1454-1466.
C2 QUOTE: "in the following vineyard results we consider just the visible berry count." (lines 1457-1466)
C2 AUTHORS' EXPLANATION: The volumetric models need cluster segmentation, which was not achieved in the vineyard (lines 1457-1466). The authors therefore use only the visible berry count for the vineyard results that follow. The arms in C2 are reported in Table V but are not used for the vineyard counts.
C2 CONDITIONS: vineyard, Traminette cultivar; cluster segmentation not achieved for the volumetric arms; number of vines, images and frame rate not stated in the lines read.

NOTES:
(1) Table IV prints R2 = 0.85 for the ellipsoid 3D model; the text at lines 1416-1417 says R2 = 0.88 for the same arm. The table and text disagree. The table value is recorded in C1 RESULTS; the text value appears only in C1 QUOTE. The source paper is not corrected here.
(2) Table V gives no MSE column, so MSE is "not stated" for C2.
(3) Calibration-source comparisons are excluded under rule (b) because they change only the calibration data, not the mechanism: Table VI (lines 1622-1631, Flame Seedless 2013: calibration from 2011 gives 6.48%, from 2012 gives 11.65%, from 2011 and 2012 gives 9.07%) and Table VII (lines 1655-1676, Chardonnay 2013). For Table VII the text (lines 1652-1654, 1661-1662) gives 2.5% for calibration from Chardonnay 2011, while the table prints -2.47% without an explicit row mapping; the mapping is not stated and is not inferred.
(4) The double-count heuristic (Section 3.3, lines 595-637: back-projection to a fruit wall, segments of roughly 0.5 m, keeping the image with the most detections per segment) has no with/without numbers. Excluded.
(5) Table II (lines 1195-1230, radial symmetry versus invariant maximal keypoint recall), Figure 9 (lines 1325-1334, with Table/text lines 1251-1301: Gabor, SIFT, FREAK and colour-only descriptors), Table III (lines 1348-1371, timings only), and Figure 11 (lines 1531-1554, threshold tau_r optimisation) are detector or feature comparisons, timings, or parameter tuning, and are excluded.
(6) Section 5.5 (lines 1467-1500) reports automated berry counts against harvest weight, with R2 0.6 to 0.73 across datasets. These are per-dataset results, not arms, and are excluded. Registration is manual for Traminette and Riesling and stereo-automated for Flame Seedless and Chardonnay (lines 1474-1478).
(7) The per-image cluster models in C1 and C2 are not cross-image linking methods. They are included under MECHANISM because they are different ways to convert the same per-image measurement into a count, which is the rule (b) criterion for regression and calibration mechanisms.
