CROP AND DATA: eggplant (Tianjin round eggplant), greenhouse; test data for counting: 3 videos V01-V03, approximately 2-3 min each, 960x544 px, 30 fps, manual counts 60/68/58 fruits; detector dataset: 4601 images from 7 videos (3681 train / 460 validation / 460 test); reference type: manual count per video (hand count)
SAME-DATA COMPARISON: yes
C1 TYPE: TRACKER
C1 ARMS: SORT, original DeepSORT, ByteTrack, and "Our Method" (improved YOLOv5s + DeepSORT + counting-zone strategy with counted-ID de-duplication). All four arms take the same detections from the improved YOLOv5s as input (lines 849-850). The arms differ in the tracker, and "Our Method" additionally differs in the counting rule: counting is triggered once when the bounding-box center enters the counting zone and the ID is not yet in the counted-ID set (lines 393-414), whereas the conventional arms use the ID of the last tracked fruit as the final count (lines 850-852).
C1 RESULTS: V01 (manual count 60): SORT count 113, counting accuracy 11.6%, relative error 88.3%; DeepSORT count 132, counting accuracy -20%, relative error 120%; ByteTrack count 211, counting accuracy -151.6%, relative error 251.6%; Our Method count 50, counting accuracy 83.3%, relative error 16.7%. V02 (manual count 68): SORT count 113, counting accuracy 33.8%, relative error 66.18%; DeepSORT count 145, counting accuracy -13.2%, relative error 113.2%; ByteTrack count 223, counting accuracy -127.9%, relative error 227.9%; Our Method count 56, counting accuracy 82.4%, relative error 17.6%. V03 (manual count 58): SORT count 124, counting accuracy -13.8%, relative error 113.8%; DeepSORT count 134, counting accuracy -31%, relative error 131%; ByteTrack count 215, counting accuracy -170.7%, relative error 270.7%; Our Method count 55, counting accuracy 94.8%, relative error 5.2%. Our Method is best on every video: highest counting accuracy and lowest relative error in V01, V02 and V03. Across the three videos its maximum accuracy is 94.83% and its mean accuracy is 86.82% (lines 951-953).
C1 WHERE: Table 4 "Comparative results of tracking algorithms" (lines 856-921); Figure 13 (lines 936-944); Section 3.5 text (lines 843-855 and 922-931); accuracy summary (lines 949-953)
C1 QUOTE: "As shown in Figure 13, in V01, the proposed method counts 50 fruits, whereas SORT, DeepSORT, and ByteTrack output 113, 132, and 211, respectively." (lines 922-924)
C1 AUTHORS' EXPLANATION: The authors state that the proposed method "maintains more stable trajectories and reduces frequent ID switches in challenging greenhouse scenes" (lines 853-855), and that "conventional trackers struggle to preserve identities under leaf occlusion and highly similar fruit appearances, leading to severe ID inflation in complex greenhouse scenes" (lines 929-931). The counting zone avoids repeated accumulation of the same target across consecutive frames: without a de-duplication constraint the same target would be repeatedly counted, so the counted-ID set limits each track ID to one count per video (lines 408-414); IoU matching and short-term track retention (max_life) are said to partially reduce ID switches (lines 415-418).
C1 CONDITIONS: 30 fps, 960x544 video; mobile platform manually towed at constant 0.1 m/s; camera 0.8 m above ground, pitch approximately -10 degrees (lines 190-197); videos include differing lighting, occlusion levels and fruit densities (lines 845-846); leaf occlusion and highly similar fruit appearance (lines 929-931); duplicate counts when previously counted fruits reappear after occlusion (lines 986-990, 1013-1015); counting-zone boundaries at 1/5 and 4/5 of image width (lines 393-396); speed and frame rate are said to affect performance (lines 1015-1017).
NOTES: (1) Lines 850-852 state that for all methods "the final count for each video is defined as the ID of the last tracked eggplant fruit", but the proposed method uses the counting zone with counted-ID de-duplication (lines 393-414); the counting rule is therefore not identical across arms, so the comparison mixes a tracker change with a counting-rule change. (2) The discussion and conclusion print 94.83% maximum and 86.82% mean accuracy (lines 952, 1010), whereas Table 4 prints rounded per-video values 83.3%, 82.4% and 94.8%. (3) Table 1 (lightweight backbones), Table 2 (module ablation), Table 3 (detector comparison) and Figures 11-12 compare detectors or detector modules only with the association unchanged, and are not recorded under the exclusion rule. (4) No comparison of counting rules is reported with separate quantitative numbers for a DeepSORT arm with and without the counting zone, so only one comparison is recorded.
