Rule (a) is therefore not verifiable from the text, so it is not recorded. (2) Buffer threshold comparison: Table 1 (full diameter, 0.08 m, lines 209-225) vs Table 2 (3/4 diameter, lines 226-244) on the same 260 repetitive and 1316 non-repetitive apples. Accuracy 83.97% vs 89.80%; repeated-apple identification 84.62% vs 67.69%; non-repeated accuracy 97.05% vs 94.00%. This varies one distance threshold within one method (the association step), not two association mechanisms, so it is not recorded as a COMPONENT or MECHANISM comparison. (4) Abstract gives "Mean absolute error ... was 12%" (line 33); the body gives MAPE 11.7% (line 248; Table 3 line 343). Conclusions give "accuracy ... was 82%" (line 357), which does not match the full-diameter accuracy of 83.97% in Table 1 nor the 89.80% in Table 2.
