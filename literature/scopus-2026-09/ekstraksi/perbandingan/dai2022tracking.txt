KEY: dai2022tracking
CROP AND DATA: cherry tomato (cultivar "jiaxina"), greenhouse, Suzhou; test data: 3 tracks (test1-3), number of images/frames not stated, actual fruit counts given for bunches 30, 68, 86 and single fruits 356, 664, 704 (Table 1, lines 243-258); reference type: hand count on tree ("compared the number of fruits obtained with the actual number of fruits obtained by manual counting", lines 227-229)
SAME-DATA COMPARISON: yes
C1 TYPE: TRACKER
C1 ARMS: Proposed method (bunch detection by YOLOv5, single-fruit count per bunch, depth filtering, tracking by predicting the bunch box from the robot's cumulative displacement and IoU > 0.8 against boxes of the previous 30 frames, lines 162-215) vs DeepSORT (same YOLOv5 bunch detector; DeepSORT tracks bunch boxes; single-fruit detection run on the crop of each tracked label, lines 269-277). Same track, same time, color video stream (lines 270-272); the two arms differ in the association/tracking method only.
C1 RESULTS: Proposed: detected bunch fruits 34 / 75 / 98; accuracy of bunch fruit counting 86.7% / 91.2% / 87.2%; number of single fruit detected 302 / 586 / 593; accuracy of single fruit counting 84.8% / 88.3% / 84.2% (test1 / test2 / test3, Table 1). DeepSORT: number of detected bunch fruits 49 / 116 / 144; accuracy of bunch fruit counting 61.2% / 58.6% / 59.7%; number of single fruit detected 265 / 586 / 593; accuracy of single fruit counting 74.3% / 77.4% / 79.2% (Table 2). Proposed is best on every printed accuracy metric in all three tests. Bunch counts: the proposed arm's detected counts are closer to the hand-counted bunch numbers (30, 68, 86). Single-fruit detected counts are identical for the two arms in test2 (586) and test3 (593) and differ in test1 (302 vs 265).
C1 WHERE: Table 1 (lines 235-266) and Table 2 (lines 292-315); text lines 267-291 for DeepSORT comparison
C1 QUOTE: "From Table 2, we can ﬁnd that the accuracy of bunch fruits counting of deepsort is lower than that of Table 1, but the number of detected tomatoes is higher than that of Table 1." (lines 278-280)
C1 AUTHORS' EXPLANATION: DeepSORT is worse because "deepsort does not have the function of deep ﬁltering, and many background tomatoes are included in the ﬁnal number" (lines 280-281). For the over-count of bunches with DeepSORT: "the bunch tomatoes were not successfully identiﬁed in several consecutive frames during the process of being tracked, and when they were identiﬁed again they were no longer successfully tracked, and then the algorithm deﬁned them as newly identiﬁed bunches of fruit" (lines 283-287). The authors conclude that "improving the accuracy of target recognition in a single frame image is very important for target tracking and counting" (lines 290-291).
C1 CONDITIONS: camera speed 0.1 m/s on the track (lines 118, 240-242, 297-299); camera Realsense D435i, color 1280x720, mounted at fixed height 1650 mm and 500-650 mm from the ridge (lines 86, 100-107); frame rate of the test video not stated (5 fps is the rate used for training images, line 118); lighting conditions across three time windows (lines 119-122) are not stated per test; occlusion between single fruits acknowledged as the cause of lower single-fruit accuracy (lines 231-234). Fruit-background separation by depth filter is the feature that differs (lines 146-147, 279-281).
NOTES: (1) DeepSORT is run with the same YOLOv5 detector (lines 272-273); the arms differ in association, so the comparison meets rule (b). (2) Table 2 has no row of actual counts; the accuracies only reproduce if the Table 1 actual counts are used: bunch 30/49=61.2%, 68/116=58.6%, 86/144=59.7% match. Single-fruit accuracy in Table 1 equals detected/actual (302/356=84.8%, 586/664=88.3%, 593/704=84.2%), but in Table 2 it does not: 265/356=74.4% (printed 74.3%), 586/664=88.3% (printed 77.4%), 593/704=84.2% (printed 79.2%). The Table 2 single-fruit accuracies for test2 and test3 are therefore inconsistent with the printed detected counts. (3) Table 1 bunch accuracy does not follow one formula from the printed counts: 1-|34-30|/30=86.7% matches test1, but test2 (75 vs 68) and test3 (98 vs 86) give 89.7% and 86.0%, not 91.2% and 87.2%. (4) Text line 268 calls DeepSORT "crowd counting algorithm"; DeepSORT is a multi-object tracker (lines 269-270). (5) Lines 327-329 repeat the same sentence about coordinate transformation twice.
