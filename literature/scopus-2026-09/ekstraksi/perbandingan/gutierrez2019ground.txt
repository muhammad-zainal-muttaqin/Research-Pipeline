KEY: gutierrez2019ground

CROP AND DATA: Mango (Mangifera indica) trees in 10 rows of an orchard block, Australia, 2017. Line-scan hyperspectral imaging from an unmanned ground vehicle. Test data: "RGB validation" 215 trees and "RGB test" 216 trees (lines 698-699, 740). Reference: RGB counts from the method of Stein et al. (2016), counted as single-view, dual-view (both sides of the tree, summed) and multi-view; not hand counts for these subsets (lines 1123-1124).

SAME-DATA COMPARISON: yes (borderline; see NOTES)

C1 TYPE: ACQUISITION (number of RGB views used as the reference count)
C1 ARMS: The hyperspectral estimate is fixed (model number 13, Table 3, applied to the same trees). The arms are the three RGB reference counts for the same trees: single-view, dual-view (sum of both sides of the same tree) and multi-view. The authors evaluate the hyperspectral counts against each reference on the same validation and test trees.
C1 RESULTS: Table 3 (rank 13, validation subset), R2 single-view 0.77, dual-view 0.83, multi-view 0.74; dual-view is best. Figure 6 test subset, R2 single-view 0.76 (panel b), dual-view 0.83 (panel d), multi-view 0.74 (panel f); dual-view is best. Figure 6 RMSE (validation/test): single 10.649 / 11.388, dual 15.115 / 15.690, multi 40.441 / 45.152 (these are on different count scales, so RMSE is not comparable across arms).
C1 WHERE: Table 3 (rank 13 row, lines 922-933, values R2Single/R2Dual/R2Multi); Figure 6 (lines 1039-1123); text lines 1197-1200.
C1 QUOTE: "Dual-view counts (both hyperspectral and RGB) are but the sum of single-view ones from both side of the same tree." (lines 1207-1208)
C1 AUTHORS' EXPLANATION: Higher dual-view R2 is explained by aggregation: summing both tree sides "reduces the magnitude in total of individual errors on either tree side" (lines 1205-1210). Multi-view RGB counts are the hardest to match because a line-scan camera "makes it impossible to implement multi-view techniques" (lines 1214-1218); the authors attribute the lower multi-view R2 to the hyperspectral camera's lower optical features (lines 1213-1216).
C1 CONDITIONS: Line-scan hyperspectral camera on an unmanned ground vehicle, one pass per row side; orchard block; 2017. The hyperspectral counts come from a single side (line-scan), and the RGB references are the variable. Figure 6 RMSE values are on each arm's own count scale.
NOTES: The "arms" here are reference counts, not counting methods; the hyperspectral pipeline is the same in all three. The comparison is included because the authors evaluate each RGB view count (single, dual, multi) as a separate counting arm on the same trees and report R2 for each, with the aggregation explanation at lines 1205-1210. Inclusion is a judgement call. The same-tree R2 values are consistent between Table 3 and Figure 6 (single 0.77/0.76, dual 0.83/0.83, multi 0.74/0.74 for validation/test). Excluded: Table 2 (field count train/test, 27 and 18 trees, different reference and different data from the RGB subsets); the repeatability comparison in Figure 9 (two dates, not arms; single-view R2 0.79 and 0.85 stated in its caption); the field-count versus hyperspectral comparison in Figure 8 (R2 0.72, one arm only, field count test). The text at line 1200 gives "0.77, 0.83 and 0.74" as the single-, dual- and multi-view R2 values, which match the validation column of Table 3.
