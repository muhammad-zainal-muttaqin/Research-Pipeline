NOTES:
1. Speed and FPS conflict. Line 617 states "The inference speed of 30 FPS", and line 777 states "roughly 30 FPS". Table III (line 679) gives YOLO-V7 speed as "18 MSec", which is about 55 FPS if taken as per-frame latency. The text does not explain the difference.
2. Table II and Table III recall values differ for the same models. Table II (lines 638-647, "10000" fruits each) gives recall YOLO-V7 93.5%, YOLO-V5 88.4%, YOLO-V4 86.9%. Table III (lines 675-691) gives recall YOLO-V7 93.2%, YOLO-V5 92.5%, YOLO-V4 90.9%. The text (lines 650-651) uses the Table II values for the "5.1%" and "6.6%" margins and the Table III values for the "0.7%" and "2.3%" margins (lines 656-658). The source of the 10000-fruit recall values (Table II) is not described in the methods.
3. Table I gives mAP@0.5 for "All" as 97.5%. The per-class values are 96.4% (O) and 98.7% (M), so the "All" value lies between them, which is consistent with a class average. Table I gives mAP@0.95 for "All" as 84.1%, while the per-class values are 81.2% (O) and 70.2% (M). The average of the two per-class values is 75.7%, which does not match 84.1%. The method for computing the "All" mAP@0.95 is not stated. Line 615-616 quotes 84.1% for mAP@0.95.
4. Line 763 states "detection precision above 94%" and "counting error rates below 5%" on video sequences. No counting table, video count, or ground-truth counting method is reported in the paper, so these counting claims are not checkable from the text. Table I precision is 94.2% on the static image set, not on video.
5. Line 396 gives "approximately 25–50 FPS" for DeepSORT. This figure is cited from refs [20][60] and is not measured by the authors.
6. Lines 396 and 402-404 describe Kalman prediction, appearance smoothing, and adaptive thresholds as part of the DeepSORT configuration. No ablation with and without these components is reported, so they are not recorded as COMPONENT comparisons.
