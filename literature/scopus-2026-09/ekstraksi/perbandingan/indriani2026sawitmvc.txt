KEY: indriani2026sawitmvc
CROP AND DATA: oil palm (Elaeis guineensis) fresh fruit bunches (TBS), SawitMVC dataset; test data: 141 trees (test split), per-tree multi-side images from 4-8 sides (dataset total 953 trees, 3,992 images, 9,823 unique bunches); reference type: per-tree ground-truth bunch counts per maturity class B1-B4 from the dataset annotations (cross-view identity labels).
SAME-DATA COMPARISON: yes
C1 TYPE: MECHANISM
C1 ARMS: (a) Naive sum: per-class sum of per-view detections, no deduplication (ground-truth detections only; no YOLO26m row printed for this arm in Table 4). (b) Global correction factor: the same naive sum divided by k = 1.8905 and rounded (run under both ground-truth and YOLO26m detections). (c) Support vector regression (SVR): one RBF-kernel regressor per class (B1-B4) predicting unique counts from a 13-dimensional cross-view feature vector (run under both ground-truth and YOLO26m detections). All arms use the same 141-tree test split and the same detections within each detection condition. Lines 521-527, 599-613.
C1 RESULTS: Table 4, as printed. Metrics are Class ±1 Acc / Tree ±1 Acc / Macro MAE / Mean Bias.
  Ground truth detections: Naive sum 50.00% / 6.38% / 2.142 / +2.142; Global correction (k = 1.89) 95.57% / 86.52% / 0.356 / +0.009; SVR 96.81% / 88.65% / 0.303 / −0.048. Best on Class ±1 Acc, Tree ±1 Acc and Macro MAE: SVR. Smallest absolute Mean Bias: Global correction (+0.009) versus SVR (−0.048) and naive sum (+2.142).
  YOLO26m detections: Global correction (k = 1.89) 72.34% / 30.50% / 1.119 / 0.381; SVR 75.35% / 33.33% / 1.027 / 0.158. Best on all three accuracy and MAE metrics: SVR. Smaller Mean Bias: SVR (0.158 vs 0.381).
C1 WHERE: Table 4 (lines 556-593); method description lines 521-526 (global factor), 602-613 (SVR); table notes a)-c) lines 594-598; text interpretation lines 619-623.
C1 QUOTE: "SVR improves on the correction factor under both conditions, most clearly on the stricter Tree ±1 accuracy and on MAE." (lines 619-620)
C1 AUTHORS' EXPLANATION: For the correction factor, the authors state that "dividing by k rescales the inflated multi-view sum by the average degree of cross-view duplication, which makes it a natural heuristic deduplication reference" (lines 599-601). For SVR, the authors state that "unlike the single-ratio divisor, SVR can learn class-specific and view-count-dependent deduplication behaviour" (lines 606-607, hyphenation at the line break removed). The authors also state that the gap between conditions is due to detection: "Detection, rather than the counting stage, is therefore the dominant source of error in the end-to-end pipeline" (lines 621-622).
C1 CONDITIONS: Detection condition (ground-truth detections vs YOLO26m detections, fine-tuned on the 716-tree training split, 60 epochs, seed 42; Table 3 overall AP50 0.531, lines 517-520, 536-537); SVR uses 13 features: naive per-class sum, maximum and mean per-class count across sides, and number of sides photographed (lines 603-605); SVR is untuned with scikit-learn defaults and no standardisation (lines 609-613); k is estimated on the training split only (lines 523-526, 600-601). Views per tree: 4-8 sides (dataset description).
NOTES: (1) The naive sum is reported only under ground-truth detections, so the naive-vs-correction-vs-SVR comparison is complete only for GT; under YOLO26m the comparison is correction vs SVR only. (2) Table 4 prints "+ 2.142" and "+ 0.009" with a space after the sign; values are copied as printed. (3) Text at lines 619-620 says SVR wins "most clearly" on Tree ±1 and MAE; the table shows SVR also wins Class ±1 Acc in both conditions, which the sentence does not mention. (4) The Mean Bias for the correction factor under GT (+0.009) is closer to zero than SVR (−0.048), so SVR is not best on every metric. (5) Each arm is a counting rule over the same per-view detections, not a tracker; the paper does not compare trackers.
