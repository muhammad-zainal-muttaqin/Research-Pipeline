CROP AND DATA: Bagged grape (Chinese paper; Bishan District, Chongqing). Detection data: 700 original images (490 train, 140 val, 70 test; training augmented to 2,100). Counting and tracking data: 6 videos of about 20 s each, 1920x1080, 30 fps (lines 121-129). Reference: annotated boxes and frame-level DarkLabel tracking annotations (lines 154-161); manual count per video (Table 5, lines 1023-1067).
SAME-DATA COMPARISON: yes

C1 TYPE: TRACKER
C1 ARMS: Same dataset and same YOLOv9s detections, with seven tracking algorithms: Sort, DeepSort, DeepMot, UAVmot, ByteTrack, NMS-ByteTrack, and AKFT (the authors' adaptive Kalman filter tracker, ByteTrack base with confidence-adaptive KF noise). Arms differ in the tracker only.
C1 RESULTS (Table 3, lines 846-901; HOTA / MOTA / IDF1 / IDSW / AFPS):
  - Sort: 51.0 / 59.9 / 67.8 / 13 / 35
  - DeepSort: 51.5 / 58.1 / 71.5 / 17 / 27
  - DeepMot: 39.4 / 54.3 / 44.4 / 28 / 30
  - UAVmot: 53.5 / 59.9 / 75.4 / 3 / 37
  - ByteTrack: 54.3 / 61.4 / 76.3 / 3 / 35
  - NMS-ByteTrack: 57.0 / 60.0 / 70.0 / 0 / 22
  - AKFT: 58.6 / 63.6 / 78.8 / 6 / 35
  - Best: AKFT on HOTA (58.6), MOTA (63.6), and IDF1 (78.8). NMS-ByteTrack has the fewest IDSW (0); UAVmot and ByteTrack have 3; AKFT has 6. AFPS is highest for ByteTrack and AKFT (35) and for UAVmot (37).
C1 WHERE: Table 3, lines 846-901; text lines 804-843; Conclusion lines 1083-1087.
C1 QUOTE: "相比其他6 种追踪算法，AKFT 在HOTA、MOTA、IDF1 等指标上显著优于其他追踪算法，分别到达了58.6%、63.6% 和78.8%。" (lines 1083-1087)
C1 AUTHORS' EXPLANATION: The authors attribute the gain to the adaptive KF, which sets noise estimates from detection confidence to reduce noise from camera shake and fast motion (lines 1309-1311 in the English abstract; Chinese text lines 804-843). Explicit reason for the IDSW difference is not stated.
C1 CONDITIONS: Six videos of about 20 s each, 1920x1080, 30 fps. Metrics are computed on the same tracking annotations. No repeated runs or significance test reported.
NOTES:
- Table 3 values were read from the extracted layout; the HOTA/MOTA/IDF1 values match the Conclusion (lines 1083-1087).
- The text says AKFT is "显著优于" (significantly better) on these metrics, but no statistical test is reported.
- AKFT is not best on IDSW, and AFPS is equal for ByteTrack and AKFT (35), which the text does not discuss.

C2 TYPE: COMPONENT
C2 ARMS: Same dataset; YOLOv9s detector with ByteTrack as base tracker, compared with the same pipeline using the adaptive Kalman filter (AKFT) in place of the base KF. Table 4 also lists EFEM and SEAM detector-module rows; those rows are detector-only and are not recorded here.
C2 RESULTS (Table 4, lines 926-992; HOTA / MOTA / IDF1 / IDSW):

  - Full AKFT vs base: HOTA +4.3, MOTA +2.2, IDF1 +2.5 (lines 922-923; Conclusion lines 1086-1087)
  - Best: the adaptive-KF arm on all three metrics. Full row values for each Table 4 row are not recoverable from the extracted layout (see NOTES).
