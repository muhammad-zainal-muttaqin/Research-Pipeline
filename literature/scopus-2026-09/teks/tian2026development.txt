A B S T R A C T
As a classic problem in computer vision, object detection has become one of the essential challenges that re­ 
searchers continue to explore. The emergence of You Only Look Once (YOLO) has transformed object detection 
from two-stage to single-stage detection, enhancing real-time performance. By transforming the object detec­ 
tion task into a regression problem, the detection speed and efficiency have also been significantly improved. 
This article elaborates on the development history of YOLO object detection algorithm in the past decade, 
with a focus on the technological evolution, evaluation indicators, dataset selection, and variant improvements 
from 2016–2025. We have systematically reviewed the technological innovations and major contributions from 
YOLOv1 to YOLOv13, including the anchor box mechanism, multi-scale prediction, attention module, lightweight 
design, and anchor-free architecture. Meanwhile, the frequency of use of evaluation metrics for object detec­ 
tion, including Frames Per Second (FPS), Giga Floating-Point Operations Per Second (GFLOPs), Precision (P), 
Recall (R), Receiver Operating Characteristic (ROC), Intersection over Union (IoU), F1-score, PR curve, Average 
Precision (AP), and Mean Average Precision (mAP), was analyzed using statistical literature methods. YOLO 
algorithm was analyzed for its proportion of utilization in object detection, image classification, and semantic 
segmentation on various datasets through commonly used datasets, PASCAL VOC, MS COCO, and ImageNet. 
Finally, the article summarizes the technological innovations and future development trends of the YOLO series, 
providing a reference for researchers.
1 . Introduction
Object detection [1–3] is one of the important tasks in the field 
of computer vision [4–6]. It aims to identify specific objects from im­ 
ages or videos and locate their positions. Two basic functions of object 
localization and recognition [7,8] are achieved. The output results of ob­ 
ject detection [9,10] usually include each detected object’s position and 
category label. Position information is typically presented in bounding 
boxes or pixel-level masks, while category labels indicate the categories 
to which objects belong. Object detection [11,12] provides key techni­ 
cal support for applications in autonomous driving [13,14], industrial 
inspection [15–17], security monitoring [18,19], and medical image 
analysis [20,21].
1.1 . Two-stage object detection
Before the emergence of YOLO [22,23] algorithms, two-stage ob­ 
ject detection methods [24,25] had long dominated research directions 
and technical applications in this field. The two-stage detectors divide 
the detection process into two relatively independent phases, which 
are region proposals and region classification or regression. The evo­ 
lution of two-stage object detection methods [26] reflects the shift in 
computer vision from traditional feature extraction to convolutional 
feature learning [27,28]. Therefore, early approaches based on slid­ 
ing windows and manually designed features were gradually replaced 
by Convolutional Neural Network (CNN)-based detection frameworks

enhanced version of Faster R-CNN [45–47] was introduced to create 
bounding boxes for each object and display their confidence scores using 
sliding-window techniques.
1.2 . Single-stage object detection
To achieve a balance between accuracy and efficiency across mul­ 
tiple indicators, single-stage detection algorithms such as the YOLO 
series [48,49], the Single-Shot Multi-Box Detector (SSD) [50–52], and 
the Detection Transformer (DETR) [53], have emerged. SSD generates 
default boxes at multiple feature map scales to predict bounding boxes 
and class probabilities simultaneously. DETR employs a Transformer ar­ 
chitecture. It treats image features as a set. The model directly outputs 
the final set, rather than a collection of candidate boxes that require 
further processing. In Table 1, the characteristics of models on the MS 
COCO dataset are provided. The training set contains approximately 
118,000 images, while the validation set includes around 5000 images. 
The experiments compare the performance of different models in terms 
of parameters, mAP, and FPS. All variants were trained for 600 epochs 
with a batch size of 16 and an initial learning rate of 0.01. 
1.3 . YOLO series object detection
YOLOv1 [22] was introduced in 2016, reformulating object detec­ 
tion as a regression problem. By dividing images into an 𝑆 × 𝑆 grid 
and directly predicting object categories, bounding box coordinates, and 
confidence scores, YOLOv1 pioneered real-time, end-to-end object de­ 
tection. Although it has limitations in small object detection [54,55] and 
localization accuracy, it laid the foundation for future research [56]. 
YOLOv2 [57] was proposed in 2017, expanding detection capabilities 
to over nine thousand object categories while maintaining adaptabil­ 
ity to different input sizes. It incorporated the Darknet-19 backbone 
network and batch normalization, significantly improving feature ex­ 
traction and model stability. Meanwhile, the introduction of Anchor 
Boxes further enhanced bounding box prediction accuracy. For instance, 
YOLOv2 was optimized for autonomous driving applications [58,59]. 
YOLOv3 [60] was released in 2018 and used Darknet-53 as its feature 
extractor. Inspired by Feature Pyramid Network (FPN) design principles, 
YOLOv3 implemented multi-scale detection, substantially improving ac­ 
curacy for objects of varying sizes. Squeeze-and-Excitation YOLOv3 
(SE-YOLOv3) [61] was developed, as a lightweight network tailored 
for multi-scale object detection in remote sensing imagery [62,63]. A 
multi-scale enhancement method [64] was proposed to refine YOLOv3 
performance on small objects. YOLOv4 [65] was introduced in 2020, 
which further enhancing detection accuracy, speed, and adaptability 
to complex scenarios. Cross Stage Partial Darknet53 (CSPDarknet53), 
Path Aggregation Network (PAN), and Complete Intersection over Union 
(CIoU) loss function were utilized in the model. It optimized the per­ 
formance of vision-based vehicle detection and classification. YOLOv5 
[39] was developed by the Ultralytics team, marking a transition from 
the Darknet framework to PyTorch. It improved accessibility and effi­ 
ciency through stride convolution layers and Space Pyramid Pooling 
Fast (SPPF). The models were provided in various sizes to suit dif­ 
ferent application requirements. Modular design and scalability have 
become one of the important benchmarks in object detection. The per­ 
formance of different YOLOv5 models [66] was compared in object 
localization and classification tasks, providing a reference for model se­ 
lection. Transformer Prediction Heads-YOLOv5 (TPH-YOLOv5) [67] was 
proposed to enhance multi-scale object detection, particularly improv­ 
ing performance for small objects in Unmanned Aerial Vehicle (UAV) 
imagery. Visual attention mechanisms were incorporated into YOLOv5 
for tomato virus disease recognition [68]. YOLOv5-Tassel [69] was de­ 
veloped, leveraging transfer learning to optimize corn tassel detection 
in UAV RGB images, supporting precision agriculture [12,70]. YOLOv6 
[71] was introduced in 2022, which was optimized for industrial ap­ 
plications [72]. Key innovations included the EfficientRep backbone, 
the Simplified Optimal Transport Assignment (SimOTA) label assign­ 
ment strategy, and the Anchor-Aided Training (AAT) mechanism, which 
significantly improved performance under resource-constrained envi­ 
ronments. An enhanced canny-devernay algorithm with YOLOv6 was 
integrated for real-time metal part defect detection [73], while a Particle 
Swarm Optimization (PSO) [74] was used to improve YOLOv6 for lung 
cancer detection and classification.
YOLOv7 [75] was proposed after 1 month of YOLOv6’s release. It 
introduced trainable Bag-of-Freebies (BoF) methods to boost accuracy 
while maintaining speed, incorporating an Extended Efficient Layer 
Aggregation Network (E-ELAN) to optimize information flow and de­ 
tection performance. YOLOv8 [76] was released by the Ultralytics 
team. It introduced scalable models tailored to various hardware con­ 
straints and expanded capabilities to include semantic segmentation, 
pose estimation, and Oriented Bounding Box (OBB) detection. Adopting 
an anchor-free detection model with a decoupled head architecture, 
YOLOv8 enabled independent processing of classification, regression, 
and object detection tasks, further pushing the boundaries of efficiency 
and accuracy. YOLOv9 [77] was developed to address the issue of infor­ 
mation loss in deep network training through its Programmable Gradient 
Information (PGI) architecture. It included a main branch, auxiliary 
reversible branches, and multi-level auxiliary information to ensure gra­ 
dient reliability. By combining the advantages of CSPNet and ELAN, 
YOLOv9 optimized computational paths for better parameter utiliza­ 
tion, high-speed inference, and accurate detection. YOLOv9 explored 
its application in vehicle detection [78], optimizing the model for as­ 
pects of urban security. YOLOv9 utilized the richer gradient information 
provided by PGI. It excels at accurately detecting and identifying vehi­ 
cles in complex environments, including partially occluded objects and 
low-light conditions.
YOLOv10 [79] eliminated the need for Non-Maximum Suppression 
(NMS) [80] through an NMS-free training with a dual-assignment 
strategy in 2024. It also introduced a lightweight classification head 
and spatial channel-decoupled downsampling to improve efficiency. 
YOLOv10 was enhanced for precise brain tumor localization [81], 
offering a novel tool for medical diagnostics. The Ultralytics team 
released YOLOv11 [82] in 2024. It adopted a new Transformer archi­ 
tecture with multimodal input. YOLOv11 improved the efficiency of 
Cross Stage Partial with kernel size 2 (C3k2) module and introduced 
the Convolutional Block with Parallel Spatial Attention (C2PSA) mod­ 
ule for better spatial attention. YOLOv11 demonstrated its improved

1.4 . Research gap and contributions
As a classic model in object detection, the YOLO model has estab­ 
lished its position in real-time object detection due to its speed and 
accuracy merits, and has undergone rapid iterations from YOLOv1 to 
YOLOv13. The current review literature focused on the technical sorting 
of YOLOv8 and earlier versions. The coverage of YOLOv9 to YOLOv13 
was seriously insufficient, making it difficult to present the key transfor­ 
mations of this series from CNN efficiency optimization to multimodal 
intelligent adaptation. It was also unable to provide the latest technical 
references. Next, the current YOLO review has suffered from fragmenta­ 
tion issues. It lacked a summary of various application scenarios and 
failed to clarify the matching relationship between technical charac­ 
teristics and scenario requirements. Therefore, we have constructed a 
specialized review framework to examine the technological evolution 
and cross-domain implementation of YOLO. A decision-making process 
was established from technical analysis to scenario-based application for 
future research and practice to provide a basis.
The development process of YOLO object detection series from 
YOLOv1 to YOLOv13 was reviewed and compared [86–88]. The main 
contributions are as follows: (1) The evolutionary differences and core 
contributions of various versions were evaluated, such as development 
frameworks, backbone networks, anchor box mechanisms, and loss func­ 
tions. (2) We deeply explored the usage preferences and importance 
of various evaluation indicators in YOLO research through bibliomet­ 
ric methods [89,90], providing empirical evidence for the selection of 
evaluation indicators. (3) Datasets and their application scenarios [91] 
were arranged, and the advantages and adaptability of different YOLO 
versions were discussed. (4) By analyzing various improved algorithms 
based on the YOLO framework [92,93], the technological breakthrough 
path was clarified. Future challenges and development directions were 
pointed out in small object detection [94] and multimodal fusion [95].
The remaining structure of it is as follows: Section 2 discusses the 
evolutionary history of the YOLO series, Section 3 addresses the evalua­ 
tion metrics for YOLO object detection, Section 4 describes the datasets 
used, and Section 5 analyzes several mainstream improvements and 
applications of the YOLO series. Finally, a summary of this paper is pro­ 
vided in Section 6, along with discussions on potential future research 
directions.
2 . Retrospective review of YOLO series
To better trace the technical evolution and design rationale of the 
YOLO series, we conducted a systematic review of its developmental 
pathway from the initial version to the most recent ones. This section 
outlines the framework of the YOLO model and elaborates on the core 
network structures and key components characterizing each version. 
Furthermore, an analysis of the strengths and limitations across different 
YOLO versions is provided.
2.1 . Establishment of model paradigm
YOLOv1 [22] used DarkNet-24 as its backbone network. The 24-layer 
convolutional network and two fully connected layers were adopted 
to regress bounding boxes to enable end-to-end training [96]. It re­ 
placed time-consuming region proposals and improved inference speed 
while maintaining accuracy. However, the grid division was coarse, 
and the number of predicted targets for each grid was limited. The 
detection performance for small targets and overlapping objects was 
poor. Moreover, the use of a fully connected structure also limited the 
positioning accuracy. YOLOv1 only supports fixed input sizes, which af­ 
fects its application flexibility. These drawbacks provided direction for 
improvement in subsequent versions.
YOLOv2 [57] introduced the DarkNet-19 backbone network, which 
consists of 19 convolutional layers and 5 max-pooling layers. It em­ 
ployed Batch Normalization (BN) technology, enabling the network to 
converge faster during training and reducing the risk of overfitting. 
Meanwhile, it introduced the anchor box mechanism, abandoning the 
approach of directly predicting bounding box coordinates in YOLOv1. 
Instead, it predefined a set of anchor boxes, and the network predicts 
the offsets of these anchor boxes, which greatly improve the precision 
of bounding box predictions. This allowed the model to detect more ob­ 
jects with irregular shapes. Although it improved small object detection 
compared to YOLOv1, it still lacked accuracy in locating small or densely 
packed objects [97–99]. In addressing the issue of target category imbal­ 
ance, it performed poorly and tended to detect categories with a larger 
number of instances [100].
YOLOv3 [60] further optimized the architecture by upgrading the 
backbone network to Darknet-53. YOLOv3 adopted a fully convolu­ 
tional network structure [101,102], removing pooling layers and fully 
connected layers [103,104]. It incorporated extensive residual connec­ 
tions in the feature extractor, addressing issues with gradient vanishing 
or explosion caused by increased network depth. This made training 
deeper networks possible while enhancing feature propagation effi­ 
ciency. Based on the FPN, YOLOv3 [105,106] introduced multi-scale 
prediction branches. Logistic regression was utilized instead of Softmax 
to achieve multi-label classification, which better fits the complex scenes 
of the real world. YOLOv3 has solved the core points of previous models 
by upgrading the backbone network, introducing multi-scale mecha­ 
nisms, and optimizing classification methods. It has established a new 
benchmark for accuracy, speed, and multi-scale collaborative evolution 
for the YOLO series. YOLOv3 achieved improvements in both accuracy 
and speed compared with YOLOv2, and has been widely applied in real-
world scenarios for real-time vehicle monitoring, traffic video analysis 
systems, and drone-based object detection. However, the issue of par­ 
tial occlusion of targets led to a degradation in detection performance 
[107]. 
YOLOv4 [65] utilized CSPDarknet53 [108] as the backbone network 
to split feature maps into two parts. This design reduced computational 
costs while maintaining rich feature learning, enhancing the network’s 
learning ability and feature extraction efficiency. The backbone net­ 
work used the Mish as an activation function to replace the previously 
used Leaky ReLU. In terms of the neck network, YOLOv4 integrated 
SPP, FPN, and PAN modules. The SPP module helped capture seman­ 
tic information across different scales. The combination of FPN and 
PAN generated pyramid-shaped feature maps, enabling the network to 
adapt to multi-scale features and better integrate and propagate infor­ 
mation. These improvements enhanced model stability and facilitated 
multi-scale learning. YOLOv4 incorporated data augmentation strate­ 
gies, such as Mosaic augmentation, building upon YOLOv3 to improve 
model robustness. It achieved small object detection [109,110] through 
the use of FPN and an increased number of anchor boxes. Hence, the

YOLOv5 [39] employed CSPDarknet53 as its backbone network and 
introduced a Focus module at the input layer. It can reduce early-stage

helping to alleviate the problem of gradient vanishing and enabling the

which automatically learns and selects optimal anchor box parameters 
according to the characteristics of the dataset during training. It can 
better fit the actual data distribution and improve detection accuracy.

has a smaller model size and lower computational resource requirements 
while maintaining high detection performance [114,115] compared to 
YOLOv4. Although certain advancements have been achieved in small 
object detection compared to previous iterations, the utilization of multi-
level interpolation-based scaling for input image adaptation during the 
prediction phase remains a limiting factor. The detection and recogni­ 
tion accuracy for ultra-small objects was still insufficient. The limitations 
of interpolation methods in preserving fine-grained details at extreme 
scales led to missed detections.
2.2 . Architectural innovation and efficiency improvement
YOLOv6 [71] introduced the Efficient-Reparameterized (Efficient-
Rep) feature extraction network based on YOLOv5, supporting selec­ 
tive pruning during inference. This design significantly enhanced model 
operational efficiency, making it particularly suitable for deployment 
on edge devices with limited computational resources. It employed a 
Re-Parameterization VGG (RepVGG) backbone network that features a 
multi-branch structure during training, increasing model flexibility and 
feature extraction capability to improve adaptability to different targets 
and scenarios. During inference, it converted to a single-branch struc­ 
ture, drastically reducing computational load and memory usage while 
significantly boosting inference speed, balancing high training perfor­ 
mance and inference efficiency. For the neck network, it adopted the 
Rep-PAN architecture, fusing feature maps of different scales through 
top-down and bottom-up path aggregation. This strengthened feature 
information transmission and sharing, helping improve detection per­ 
formance for targets of varying sizes. YOLOv6 detection head replaced 
the coupled head of YOLOv5 with an efficient decoupled head con­ 
structed using a hybrid channel strategy. Therefore, it was suitable for 
deployment on edge devices with limited computing resources, improv­ 
ing operational efficiency while maintaining accuracy. However, the 
dependence of the model on structural re-parameterization also brought 
limitations. The complex multi-branch design in the training stage in­ 
creased memory consumption and implementation complexity, resulting 
in unstable generalization performance across different edge computing 
platforms.
YOLOv7 [75] backbone network consists of Conv, E-ELAN, RepConv, 
and Spatial Pyramid Pooling Cross-Stage Partial Channel (SPPCSPC) lay­ 
ers. Feature extraction efficiency is optimized through grouped convo­ 
lutions and channel rearrangement enhancing multi-scale feature fusion 
capability [116–118]. The neck is composed of PFN and PANet. YOLOv7 
uses RepConv to merge multi-branch convolutional structures during 
training into a single convolution during inference, reducing computa­ 
tion and improving inference speed while optimizing cross-scale feature 
fusion. The core breakthrough of YOLOv7 is the synchronous improve­ 
ment of accuracy and speed through module cascade optimization 
and dynamic training strategy, without increasing computational com­ 
plexity. However, YOLOv7 relies on graph optimization and hardware 
acceleration, which limits its actual gain on edge devices. The detection 
accuracy of common targets has been improved, but the improvement 
for small targets is limited. It also indicates that there is still room for 
optimization in its feature fusion mechanism.
YOLOv8 [76] has gained significant popularity in the YOLO series 
[119–121]. It replaced the C3 module in YOLOv5 with the Cross-Stage 
Partial with Feature Fusion (C2f) module, enhancing feature extraction 
capabilities and achieving model lightweighting by adding gradient flow 
branches and introducing additional split operations. The C2f module 
consists of two Conv2d modules and two bottleneck modules, while 
the CSP modules in CSP-PANet within the Neck are also upgraded to 
C2f. The C2f module assisted the model in capturing more detailed 
features. By adopting a decoupled head structure that separates clas­ 
sification and regression tasks, YOLOv8 improved detection accuracy 
[122,123]. The decoupled detection head supported anchor-free detec­ 
tion, reducing dependency on predefined anchor boxes. YOLOv8 has 
achieved systematic innovation in accuracy and flexibility through an 
anchor-free mechanism, decoupling the detection head and C2f mod­ 
ule. These designs enabled YOLOv8 to perform excellently in industrial 
quality inspection and autonomous driving which require high-precision 
positioning, and its unified architecture supports multi-task extensions. 
YOLOv8 has a mature ecosystem, detailed documentation, and an ac­ 
tive community, greatly reducing the barriers to development and 
deployment. However, YOLOv8 still experiences false positives or false 
negatives for complex backgrounds and targets with similar colors to the 
background.
The backbone network of YOLOv9 [77] was EfficientRepV2, which 
was mainly constructed based on the RepNCSPELAN4 module [124]. It 
proposed the PGI and Generalized Efficient Layer Aggregation Network 
(GELAN) structures, theoretically solving the information loss problem 
in deep networks. The PGI framework aimed to overcome the inherent 
information bottleneck of deep neural networks, enabling the deep su­ 
pervision mechanism to be compatible with lightweight architectures. 
It improved the model accuracy and learning ability by providing reli­ 
able gradient information. Meanwhile, the GELAN structure optimized 
object detection performance through efficient layer aggregation and 
lightweight design, supporting flexible configuration of computational 
blocks and depth, and was suitable for various deployment scenarios 
from servers to edge devices. GELAN embedded the C3 module into the 
C2f structure to further enhance the model’s adaptability and scalabil­ 
ity. These improvements enabled YOLOv9 to improve feature extraction 
and detection accuracy while maintaining efficient inference [125]. The 
detection performance of YOLOv9 was impeded for small or highly 
overlapping objects, a weakness attributable to its grid-based predic­ 
tion system. This framework often failed to resolve multiple objects that 
coalesced within a single grid cell.
2.3 . Framework fusion and collaborative optimization
YOLOv10 [79] adopted the EfficientRepV3 backbone network, in­ 
corporating Spatial-Channel Decoupled Downsampling (SCDown) and 
an order-based block allocation strategy to enhance detection effi­ 
ciency [126]. During both training and inference phases, YOLOv10 
introduced a novel NMS-free consistent dual-assignment training strat­ 
egy, eliminating the inference latency caused by traditional NMS-based 
post-processing in YOLO models and achieving more efficient object de­ 
tection. While maintaining a similar overall architecture to YOLOv8, 
YOLOv10 features several key module upgrades, including SCDown, 
Partial Self-Attention (PSA), large-kernel convolutions, and Cross-Stage 
Feature Coupled Information Bottleneck(C2fCIB) modules, all of which 
are designed to boost detection efficiency and learning capability with

minimal computational overhead. YOLOv10 presented itself for deploy­ 
ment in scenarios with constrained computational resources and strin­ 
gent real-time demands, such as mobile real-time video analytics and 
autonomous drone navigation. However, its performance in distinguish­ 
ing between highly overlapping objects required empirical validation 
following the removal of the NMS module. Furthermore, the model 
exhibited heightened sensitivity to data quality and hyperparameter 
tuning, which can impact training convergence stability. These inher­ 
ent characteristics limited its effectiveness in dense object detection 
scenarios.
YOLOv11 [83,127] enhanced both the backbone and neck archi­ 
tectures by replacing the C2f module from YOLOv10 with the C3k2 
module, combined with the C2PSA mechanism. This mechanism em­ 
bedded pyramid spatial attention within the C2 module to achieve 
multi-head attention enhancement. Two depthwise convolutional layers 
were introduced in the head section. These improvements reduced both 
the number of parameters and computational complexity while boost­ 
ing model performance. The anchor box strategy was upgraded from 
the static configuration in YOLOv8 and the semi-adaptive optimization 
in YOLOv10 to a fully adaptive mechanism. This mechanism was auto­ 
matically adapted to the target scale distribution of different datasets 
without requiring manual tuning. Based on CIoU, SIoU, and DIoU, EIoU 
was introduced as a loss function. By integrating constraints on over­ 
lap area, aspect ratio, and center point deviation, it reduced localization 
errors of bounding boxes and improved localization accuracy in dense 
object scenarios. Furthermore, the SPPF module for multi-scale feature 
fusion was continuously optimized, strengthening the fusion of shallow 
small object features and deep semantic features. YOLOv11 [128] uti­ 
lized a Transformer architecture, dynamic head design, and dual label 
assignment, exhibiting performance in object detection, pose estimation, 
and oriented object detection. It achieved comprehensive improvements 
in speed, accuracy, and flexibility. YOLOv11s attained 54.7 % mAP on 
the MS COCO dataset, which was 0.6 mAP higher than YOLOv10s. The 
main improvements included more efficient feature extraction, faster 
inference speed, reduced parameter count, stronger cross-domain adapt­ 
ability, and broader task support. The application of YOLOv11 was 
primarily concentrated in precision agriculture under complex environ­ 
ments and intelligent transportation systems. It was further lightweight 
compared to YOLOv10, making it suitable for resource-constrained edge 
devices performing complex perception tasks. However, YOLOv11 posed 
challenges in accurately estimating the position and pose of symmetri­ 
cal objects, which limited its applicability in industrial scenarios. The 
introduction of the C3k2 module, while improving performance, was 
accompanied by increased computational complexity, and the model’s 
lightweight design remained an issue.
YOLOv12 [84] introduced an attention-centric architecture by in­ 
tegrating A2 into its one-stage detection framework, optimized with 
flash attention [129] for improved memory access and inference speed. 
Addressing the gradient blockage and optimization instability issues 
in traditional ELAN modules with attention mechanisms, YOLOv12 
employed the R-ELAN, introducing residual shortcuts and scaling fac­ 
tors to redesign feature aggregation. This approach used a bottleneck 
structure, adjusted channel dimensions, and streamlined computation 
to reduce both computational costs and memory footprint [130–132]. 
YOLOv12s contained only 15.2 M parameters, representing an 18 % re­ 
duction compared to YOLOv11s. In performance evaluation on the MS 
COCO dataset, YOLOv12x achieved 55.8 % mAP, surpassing YOLOv11x 
by 1.1 %, while YOLOv12n demonstrated a 2.1 % mAP improve­ 
ment over YOLOv10n. The deployment efficiency and compatibility 
were substantially enhanced, with its computational load amounting 
to only 36 % of RT-DETR’s requirements. It maintained compatibility 
with extended tasks, including instance segmentation and pose esti­ 
mation. The attention architecture and R-ELAN network in YOLOv12 
were specifically designed for high-precision detection in complex sce­ 
narios. The model demonstrated exceptional performance, particularly 
in challenging environments involving high-resolution inputs, severe 
occlusion, and low-illumination conditions. YOLOv12 not only deliv­ 
ered numerical performance improvements but also signified a fun­ 
damental transition for the YOLO series, moving from conventional 
CNN optimization to a developmental phase characterized by the in­ 
tegration of attention mechanisms and CNNs.Despite its architectural 
innovations, YOLOv12 exhibited several technical limitations that re­ 
quired further improvement. The integration of attention mechanisms 
resulted in slower inference speeds compared to its predecessor and in­ 
creased computational demands that limited its deployment flexibility 
on resource-constrained devices. The model performance optimization 
depended on specific hardware architectures, restricting its broader ap­ 
plication across diverse edge computing platforms. Furthermore, the 
training process demanded substantially more computational resources 
and time, with the complex attention-based architecture presenting chal­ 
lenges in maintaining training stability and optimization efficiency. 
The verification of its capability in small object detection remained 
insufficiently demonstrated.
YOLOv13 [85] reconstructed the architecture with multimodality as 
its core. It introduced architecture through the HyperACE mechanism 
and FullPAD paradigm, which collected multi-scale feature maps from 
the backbone network into HyperACE and then redistributed the en­ 
hanced features to various network nodes through different FullPAD 
tunnels. The implementation of gated fusion technology enabled ef­ 
fective information flow and integration to satisfy global fusion and 
redistribution of multi-scale feature maps. This architecture allowed 
the network to perceive deep semantic relationships across spatial 
positions and scales. It demonstrated enhanced capability in model­ 
ing anatomical relationships between organs in medical imaging to 
improve lesion localization accuracy. It can understand the spatial topol­ 
ogy of ground objects in remote sensing monitoring for more precise 
classification. It analyzed dynamic interactions between vehicles and 
pedestrians in intelligent transportation systems to provide deeper scene 
understanding for decision-making. It recognized component assembly 
relationships in industrial quality inspection to identify relational de­ 
fects undetectable by traditional methods. This accuracy improvement 
did not rely solely on parameter accumulation but rather stemmed 
from the effectiveness of global relationship modeling. These scenar­ 
ios required models not only to detect targets but also to make precise 
judgments through understanding target-environment and target-target 
relationships. The development of YOLOv13 faced several limitations. 
The implementation of HyperACE mechanisms and FullPAD paradigms, 
while enhancing contextual understanding, substantially increased com­ 
putational complexity and memory requirements. The complex gated 
fusion technology and multi-scale feature redistribution mechanisms 
presented challenges in training stability and optimization efficiency, 
often requiring extensive hyperparameter tuning and longer training 
durations. These limitations illuminated the challenge in balancing 
architectural sophistication with operational practicality in object de­ 
tection systems. A detailed overview of the development process from 
YOLOv1 to YOLOv13 is provided in Tables 2 and 3. It includes con­ 
tributions in terms of release time, key technologies, and the bal­ 
ance between accuracy and speed for each version. The improvement 
of the YOLO series is elaborated from single-stage real-time detec­ 
tion algorithms to multi-tasking, lightweight, and high-performance 
architectures.

FPS, GFLOPs, P, R, ROC, IoU, F1-score, PR curve, AP, and mAP. As a 
comprehensive indicator, mAP can integratively reflect P and R [136].
3.1 . FPS
FPS [137] is one of the key metrics for evaluating the speed perfor­ 
mance of a model. This metric primarily measures the inference speed 
of the model. In object detection [138,139], FPS represents the num­ 
ber of images that can be processed per second. A higher FPS value 
indicates that the model can detect more images per second, leading 
to higher detection efficiency and lower inference latency [140]. This 
metric is crucial for achieving real-time detection, as only a fast pro­ 
cessing speed can meet the requirements of real-time applications. For 
scenarios with high real-time requirements, the FPS performance met­ 
ric is essential for autonomous driving and road anomaly detection. A 
high FPS value means that the YOLO algorithm model can detect target 
objects more rapidly, which directly affects the overall performance of 
the system and the user experience [141].
3.2 . GFLOPs
GFLOPs [142] is used to measure the speed and capability of a model 
in performing floating-point operations. It represents the number of bil­ 
lions of floating-point operations executed per second, reflecting the 
computational complexity and efficiency of the model when processing 
image data. A high GFLOPs value typically indicates that the model can 
process images faster, thereby achieving higher frame rates and real-
time performance [143]. However, it may also imply that the model 
requires more powerful computing hardware to support it. In the op­ 
timization and comparison of YOLO models, GFLOPs is one of the key 
metrics for evaluating model performance and hardware adaptability. It 
helps researchers and developers select appropriate model versions and

3.3 . P and R
P and R [144] are crucial metrics for evaluating the accuracy of ma­ 
chine learning classifiers. For binary classification tasks, a confusion 
matrix is commonly used to illustrate the relationship between pre­ 
dicted results and actual labels. Table 4 shows an example of a confusion

the ground truth label is also negative. False Positive (FP) represents that 
the prediction is positive, but the ground truth label is negative. False 
Negative (FN) shows that the prediction is negative, but the ground truth 
label is positive. 
P measures the proportion of correctly predicted positive samples 
among all samples predicted as positive. This ratio helps determine the 
accuracy of a classifier in classifying positive samples. R refers to the 
proportion of actual positive samples correctly predicted as positive, re­ 
flecting the model’s ability to identify all object instances in an image.

3.4 . ROC
ROC curve [147] serves as a tool for evaluating the performance of 
classification models. It is plotted with the False Positive Rate (FPR) 
on the 𝑥-axis and the True Positive Rate (TPR) on the 𝑦-axis by vary­ 
ing prediction probability thresholds in binary classification problems 
to obtain corresponding coordinate points. The key characteristic of 
the ROC curve is that model performance improves as the curve ap­ 
proaches the top-left corner, indicating higher TPR and lower FPR 
[148]. The diagonal line represents random guessing, where FPR equals 
TPR. The performance metric for ROC is the Area Under Curve (AUC), 
which ranges between 0.5 and 1. A value closer to 1 indicates superior 
model performance, while an AUC of 0.5 signifies prediction accuracy 
equivalent to random guessing.

Jaccard index. IoU serves as a crucial measure for evaluating object 
detection accuracy and assessing a model’s localization performance. 
A higher IoU value indicates that the target position predicted by the 
YOLO algorithm more closely matches the actual target location [150].

PASCAL VOC dataset [165] is a classic in computer vision [185]. 
The primary tasks are object detection, image classification, semantic 
segmentation, and action classification. The PASCAL VOC 2007 version

11,540 images, covering 20 common categories like humans, vehicles, 
animals, and furniture, providing researchers with extensive training

and SSD, various object detection algorithms [186]. The PASCAL VOC 
dataset is also used for object classification tasks. It can be utilized 
to train and test traditional feature-based machine learning and deep 
learning-based [187,188] convolutional neural network models. It can 
assess classification accuracy across different object categories and con­ 
duct performance comparisons and improvements. Additionally, the 
PASCAL VOC dataset provides pixel-level semantic segmentation an­ 
notations, making it a crucial dataset for semantic segmentation tasks.

of the studies extend the dataset to emerging directions for action recog­

500 validation images, and 1757 test images, with an average of 7 
pedestrians per image, providing visible region and full-body annota­ 
tions. The dataset covers urban street scenes at different times and under 
various weather conditions, featuring detailed annotations and a large 
sample size. It particularly emphasizes pedestrians in small-target, par­ 
tially occluded, and dense scenarios, offering rich training materials for 
pedestrian detection algorithms. It is widely used to evaluate pedes­ 
trian detection algorithm performance and provides a foundation for 
deep learning model training [211–213]. It applies to intelligent trans­ 
portation systems, security monitoring, autonomous driving, and other 
fields. GQA [176] is a large-scale visual question– answering dataset cre­ 
ated in 2019. It includes 110,000 real images from the Visual Genome 
dataset and 22 million balanced question–answer pairs, covering 3097 
vocabularies and 1878 answer types. Each training and validation im­ 
age is associated with scene graph annotations describing the class, 
attributes, and pairwise relationships of objects in the scene. Noted for 
its rich content and diverse question–answer forms, GQA covers basic 
visual question– answering as well as complex reasoning and contex­ 
tual understanding tasks. Providing detailed annotations and metadata, 
it suits research on various visual question– answering and image un­ 
derstanding tasks [214,215], serving as an important benchmark in 
the visual question– answering field. It has been widely applied in 
deep learning and computer vision research, with related achievements 
used in practical scenarios like intelligent assistants and autonomous 
driving.
INRIA dataset [177] is a collection of labeled images of standing 
or walking persons [216], where the HOG-SVM pedestrian detection 
algorithm was proposed. Containing 2573 images, the dataset covers 
different lighting conditions, pedestrian postures, and background com­ 
plexities, including original images and annotations of upright pedes­ 
trians. VisDrone [178] is a large-scale drone vision dataset. It includes 
288 video clips and 10,209 static images, covering 10 common object 
categories, including pedestrians, vehicles, and bicycles, with a spe­ 
cial focus on small object detection [217,218]. Among them, 60 % of 
targets are smaller than 20 pixels. It is suitable for object detection re­ 
search [219–221] in complex environments, especially for small object 
detection tasks in drone aerial photography scenarios. It is widely used 
for algorithm training and evaluation in autonomous driving, security 
monitoring, smart cities, and other fields. VisDrone provides a standard 
benchmark for academic and industrial communities to assess object 
detection algorithm performance.
5 . Variant improvements of the main algorithms in successive 
generations of YOLO
5.1 . YOLOX
YOLOX [222] is an innovation based on YOLOv3. It can directly pre­ 
dict the center point of the target and the size of the bounding box, 
simplifies the network, and avoids the limitations of anchor boxes by 
adopting an anchor-free architecture. It uses a decoupled head to inde­ 
pendently process the classification [223,224] and regression branches, 
improving the model’s flexibility. With the SimOTA dynamic label 
assignment strategy, it dynamically divides positive and negative sam­ 
ples according to the matching degree between the predicted box and 
the ground truth box, optimizing the training process. Meanwhile, it 
uses the data augmentation techniques of Mosaic plus MixUp to en­ 
hance the model’s generalization ability. Experiments show that YOLOX 
achieves 47.3 % AP on MS COCO dataset, an increase of 3 % AP com­ 
pared to YOLOv3. YOLOX not only refreshed the performance record 
of the YOLO series at that time, but also the proposed anchor-free plus 
SimOTA scheme has become an important technical basis for YOLOv6 
and YOLOv7 subsequent algorithms.
YOLOX improves the YOLO series by introducing an anchor-free box 
design, decoupling heads, and SimOTA dynamic label assignment. But 
it does have some limitations in terms of architecture, functionality, 
and ecosystem. (1) The ability to extract deep features is limited by in­ 
formation loss and gradient degradation. It is recommended to learn 
from YOLOv9 and introduce PGI and GELAN to ensure gradient flow 
and improve parameter utilization. (2) It focuses on object detection, 
lacking support for multitasking [225,226]. We can refer to YOLOv11 
and other network improvements for a unified multitasking architec­ 
ture that supports detection, instance segmentation, pose estimation, 
and classification. (3) The ecosystem support is weak, lacking continu­ 
ous maintenance and integrated tools, and the deployment optimization 
cost is high. Ultralytics has built a comprehensive ecosystem, providing 
unified APIs, active communities, documentation, and Ultralytics HUB 
tools, greatly simplifying the process from training to deployment.

5.2 . YOLO-SLD
YOLO-SLD [227] is a dedicated license plate detection model im­ 
proved based on YOLOv7. Integrating the parameter-free SimAM at­ 
tention mechanism significantly enhances its detection performance, 
achieving an mAP@0.5 of 98.91 % on the CCPD dataset. It has a 0.47 % 
improvement compared to the original model. It has optimized the de­ 
tection ability under low or strong light extreme conditions, with an 
accuracy improvement of 3.2 %. This model embeds the SimAM module 
in the backbone and head of YOLOv7. Through the energy function, it 
dynamically allocates spatial-channel weights, strengthening the license 
plate feature extraction without increasing the number of parameters. 
It reduces 1.2 million parameters and maintains the real-time advan­ 
tage of the YOLO series [228–230]. Its innovative SimAM-ELAN module 
and multi-level feature fusion design enable the model to perform excel­ 
lently in tilted and occluded complex scenarios. It is suitable for practical 
applications at toll stations and traffic violation monitoring in intelli­ 
gent transportation systems, providing a high-precision and lightweight 
solution for license plate detection.
YOLO-SLD achieves accuracy improvement and model lightweight­ 
ing effects in license plate detection tasks by integrating a parameter-free 
SimAM attention mechanism in YOLOv7. But it has some limita­ 
tions in terms of core architecture and task breadth. (1) Backbone 
networks and label allocation strategies are not advanced. The atten­ 
tion mechanism SimAM has no parameters. Therefore, its expressive 
ability is weaker than that of complex attention modules with pa­ 
rameters. YOLOv12 introduces A2 and R-ELAN modules to enhance 
gradient flow while reducing computational complexity, and is com­ 
plemented by FlashAttention to optimize memory access. YOLO26 
[231] adopts Progressive Loss Balancing (ProgLoss) and Small Target 
Aware Label Assignment (STAL) to improve training stability and small 
object detection accuracy. (2) Focusing on license plate object detec­ 
tion, it lacks support for multitasking [232,233], such as segmentation 
and pose estimation. It is recommended that YOLOv11 and YOLO26 
multi-task architectures be combined to support instance segmenta­ 
tion, pose estimation, image classification, and oriented bounding box 
detection.
5.3 . YOLO-World
YOLO-World [234] achieves breakthrough performance in detecting 
objects [235–237] of any category without training by integrating visual 
language modeling technology. It is pre-trained on large-scale visual lan­ 
guage datasets in Objects365 and GQA, and uses the CLIP text encoder 
and the innovative RepVL-PAN for multimodal feature fusion. It achieves 
a zero-shot detection accuracy of 35.4 AP on the LVIS dataset, while 
maintaining a real-time processing speed of 52 FPS, which is 20 times 
faster than traditional open-vocabulary detectors. Its core technologies 
include prompt-then-detect, which avoids real-time encoding by caching 
text embeddings and has a dynamic category adaptation mechanism. 
This technology has been applied to scenarios in autonomous driv­ 
ing, environmental perception, and intelligent monitoring for abnormal 
object recognition. However, there are limitations in the detection ac­ 
curacy of small targets, which have promoted the application process of 
open-vocabulary detection technology in the industrial field.
YOLO-World has a good balance between open vocabulary and real-
time performance. But it has some limitations in terms of architectural 
dynamism and task breadth. (1) It needs to be given category words 
in advance and belongs to static open vocabulary detection. The com­ 
putational efficiency will significantly decreases when the vocabulary is 
large. YOLO-UniOW [238] solves this problem by introducing a dynamic 
category awareness mechanism and an uncertainty calibration mod­ 
ule, which supports zero sample category extension and can adaptively 
distinguish between known and unknown categories. (2) YOLO-World 
focuses on object detection, lacking support for multitasking, such as 
segmentation. YOLOE [239] multitasking architecture supports instance 
segmentation and integrates visual cues to improve performance.
5.4 . LP-YOLO
LP-YOLO [240] is a lightweight pedestrian detection algorithm 
improved based on YOLOv11. In response to the challenges of occlu­ 
sion, scale variation, and background interference faced in pedestrian 
detection in complex urban environments, the CSP Bottleneck with 
Spatial Channel convolutions (C3k2SC) module is introduced to reduce 
spatial and channel redundancy in feature extraction, reducing com­ 
putational cost and the number of parameters while improving the 
efficiency of feature representation. The SCDown module is used for 
spatial-channel decoupling downsampling, which not only reduces com­ 
putational requirements but also improves detection performance. The 
Feature Fusion Receptive-field Attention Convolution (FFRFA) is embed­ 
ded into the feature fusion process of the Neck and positioned before the 
small object detection head [241–243], enabling the network to pre­ 
serve and enhance relevant small-scale information better. These three 
innovative structures enable the model to achieve a 24.8 % reduction 
in parameters, a 7.94 % reduction in computational cost, and a 1.6 % 
improvement in mAP@0.5 on CityPersons dataset. It demonstrates ex­ 
cellent generalization ability in multi-scene datasets such as VisDrone 
and INRIA. Especially in the detection of small pedestrian objects, the 
missed detection rate is significantly reduced, providing an efficient 
solution for real-time pedestrian detection on edge devices.
Although LP-YOLO has a lightweight design, and improves the accu­ 
racy of the model based on YOLOv11. There are still demerits in model 
architecture, training strategies, task breadth, and generalization abil­ 
ity. (1) It has not fully solved the problem of feature loss caused by 
small target missed detection and occlusion. There is still room for op­ 
timization in the loss balance and label allocation strategy during the 
training process. (2) LP-YOLO focuses on pedestrian target detection, 
lacking support for multitasking such as segmentation and classification.

6 . Discussion and conclusions
This article took the development of YOLO object detection as a clue, 
introduced the relevant knowledge of single-stage and two-stage detec­ 
tion algorithms, and compared and analyzed their performance. Based 
on the core structure of the algorithm, a detailed introduction was given 
to the updates and iterations of the YOLO series in the past decade. 
Then, statistical analysis was conducted on the literature to compare 
the usage tendencies of various evaluation metrics in YOLO object de­ 
tection by researchers. Subsequently, commonly used classic datasets 
were introduced, and the main research directions of the used datasets 
were analyzed. Finally, we introduced a part of the improved mod­ 
els based on YOLO. The development of YOLO faces multi-dimensional 
challenges and transformations, involving a wider range of application 
scenarios and more complex spatial information processing require­ 
ments. These challenges not only drive YOLO’s technological iteration, 
but also make it more in line with practical scenario requirements. The 
development trend of YOLO will deeply integrate the technological ideas 
of these directions, while maintaining real-time advantages, continu­ 
ously improving detection accuracy, generalization ability, and scene 
adaptability.
6.1 . Key unresolved issues in the YOLO series
The evolution of YOLO faces multidimensional challenges and trans­ 
formations, involving a wider range of application scenarios and more 
complex spatial information processing requirements, including small 
object detection, few-shot learning, open-world, and open-vocabulary 
object detection. These challenges will drive the future technological 
development of YOLO, enhancing its alignment with the demands of 
practical scene needs. In small target detection, YOLO can evolve from 
prioritizing speed to emphasizing both speed and accuracy for small 
targets. By enhancing multi-scale feature fusion and optimizing low-
level feature preservation, YOLO improves its ability to recognize small 
targets to meet the needs of remote sensing, monitoring, and other sce­ 
narios. Due to the high cost of annotated data and the scarcity of samples 
in practical scenarios. Models often struggle to learn effective discrim­ 
inative features from limited data, making them prone to overfitting 
in few-shot learning regimes. To solve this problem, an efficient fea­ 
ture extraction and storage mechanism can be designed to enable the 
model to learn key features from a small number of annotated samples 
and establish feature stores. A subsequent feature comparison module 
can then compute the similarity between new samples and this stored 
feature bank, bolstering the model’s generalization capability in data-
scarce conditions. This approach reduces data dependency, alleviates 
overfitting, and enables YOLO to maintain robust detection performance 
even when training samples are limited. Furthermore, a universal fea­ 
ture representation template can be constructed within a meta-learning 
framework. By integrating contrastive learning mechanisms, this facili­ 
tates efficient feature encoding and matching, thereby reducing reliance 
on large-scale annotated datasets and effectively addressing the issue of 
sample scarcity. In open-world and open-vocabulary object detection, 
YOLO can incorporate incremental learning to address unknown cat­ 
egories and continuous learning needs, while integrating cross-modal 
semantic association capabilities. By combining with visual text pre-
training models, it can recognize untrained categories, break through 
fixed category limitations, and evolve into a more universal detector. In 
the future, YOLO needs to improve detection accuracy, generalization 
ability, and scene adaptability while maintaining its real-time merits. 
It can be used to address the challenges of YOLO in scenarios such as 
severe occlusion, extreme illumination, and low-resolution images.
