Abstract— USB Palm Oil Counting (Unstripped Bunch) is 
important in oil palm processing mills. Information on the 
number of USBs is essential because it shows the level of 
efficiency of the palm oil processing plant. Due to its complexity, 
palm oil mills rely solely on manual calculations, which is 
inefficient workforce waste. Challenging aspects such as partial 
occlusion, overlap, and even different perspectives limit the use 
of traditional computer vision techniques. In recent years, deep 
learning has become increasingly popular for computer vision 
applications due to its superior performance over conventional 
methods. This paper proposes a deep learning solution to solve 
USB computing problems in palm oil mills. Our proposed 
automated USB counter system consists of an object detector 
built on the RCNN Faster architecture and an object tracker 
made in the euclidean distance. Our proposed system identifies 
and counts USBs with an average accuracy of 71.5% in testing. 
Keywords—automatic, unstripped bunch, counting, faster r-
cnn, object, tracker 
I. INTRODUCTION  
The processing of oil palm fruit into CPO is a complex 
process. Because the oil palm production process is 
complicated, there will be losses. Losses in oil palm mills 
include losses caused by the poor implementation of the 
sterilization process and the extraction of oil palm fruit from 
bunches[1]. 
Improper sterilization and seeding process of oil palm fruit 
bunch will result in empty bunches containing oil palm fruit. 
This bunch is called Unstripped Bunch or USB. In Malaysia, 
loss in USB,  estimated reaches an average of 0.05% / TBS[2]. 
In one case study, in Indonesia (another major CPO producer), 
loss caused by USB is a bit bigger, 2.2%[3]. In some cases 
where the bunches are not treated properly, USB loss could 
reach 40% / TBS[4]. 
Based on this, we can conclude, the performance of the oil 
palm mills can be seen based on small USB losses; in other 
words, the performance measurement of oil palm mills can be 
seen based on USB loss; unfortunately, no method can 
automatically count the USB. So far, the USB surveillance has 
been done manually and is neglected in some cases[5].  
Object counting is a major task in computer vision and has 
been widely applied to crowd monitoring[6] [7] [8] [9]  [10] 
[11] [12] [13], blood cell counting[14] [15] [16] , and fruits 
detection[17] [18] [19]. Initially, the counting task was carried 
out through object detection. However, later mainstream 
methods involved density map regression. Although object 
counting is still a challenge because images have various 
appearances, scale changes, and object distributions are not 
homogeneous, because of its extensive application, automatic 
object counter remains an area that attracts researchers to 
develop its application or method. 
In the production process of an industry, it is often 
necessary to calculate objects that are run on conveyors. This 
problem is usually solved using sensors or electronic 
transducers such as photo or laser sensors instead of computer 
vision[20]. However, along with the development of computer 
vision technology and driven by unique conditions, several 
researchers have tried to develop counting objects on a 
conveyor using image processing[21]. 
The counting of a USB on a running conveyor requires a 
different solution. Attempts to count objects on a conveyor 
belt as carried out by Vanijjirattikhan et al. cannot be carried 
out for this USB counting. The redundancy count and line 
camera methods do not detect objects of more than one class 
on the conveyor. In this case, there are two objects, namely 
EFB and USB, and these two objects must be distinguished. 
Another problem faced by the direct counting method is the 
occurrence of double-counting, where the same object is 
counted twice. The researcher solves this problem by 
calculating lines that form the calculated area. This research 
project will use an object tracking approach to solve this 
problem. 
This research aims to develop a UB counting system by 
utilizing faster R-CNN as an object detector and a tracking 
method based on Euclidean distance to reduce double 
counting.

B. Object detection and  Object Counting With Deep 
Learning 
Researchers have exploited the profound learning ability 
to recognize and detect objects. Its application is extensive in 
agriculture, health, transportation, medical, and even defense. 
Deep learning has proven to be the most valuable solution for 
object detection in different circumstances.  
Object learning systems based on deep learning are widely 
used in almost all fields of agriculture, such as object 
identification[22], object classification [12] [13] [25], and 
object detection and counting [26] [18].  
Several researchers have developed a deep learning 
approach for object counting in agriculture.   The detection 
and counting of tomatoes were carried out by Afonso et al. In 
his study, Afonso et al. succeeded in developing a tomatoes 
detection and counting system using deep learning. Tian et al. 
and Cowton et al. extended an automatic pig counter for pig 
farming[27]. This counting system is also based on deep 
knowledge. However, deep learning-based object detection 
application used to calculate USB in palm oil production has 
never been implemented. In this paper, we propose a running 
USB counter based on the faster RCNN-based USB detection. 
III. OBJECT COUNTING WITH FASTER RCNN 
Fig. 3  shows a proposed blog diagram USB counter 
system based on Faster RCNN. The main components of this 
USB counter system are the USB detector component and the 
USB counter component. 
 
Fig. 3. USB Counting System Blog Diagram 
We propose fruitlets detection and bunch detection for 
detecting USB.  The USB detector backbone is built from 
Faster RCNN. The output for object detection using a faster 
RCNN is in the form of two parameters. The first parameter is 
a classification parameter, while the second is a bounding box 
parameter, a regression parameter. We will take the bounding 
box parameter for the USB counter to calculate the USB 
centroid and check whether the USB is an old one or a new 
one.  
Based on the basic definition that USB is EFB which still 
has a fruitlet in it, to justify a sign is USB or not based on the 
presence of a fruitlet in the bunch. In labeling, we propose 
detecting one fruitlet, two fruitlets, three fruitlets, and four 
fruitlets. This selection is based on the consideration that in 
factory operations, the definition of USB is often different in 
each palm oil mills company. A bunch is said to be a USB if 
inside the bunch there are fruitlets. Based on this definition, 
the steps are taken to determine whether a bunch is a USB 
bunch or not; the first step is to get the BBox coordinates 
((X1usb, Y1usb, X2usb, Y2usb) ) of the bunch and then get 
the fruitlet coordinates (X1fruitlet, Y1fruitlet, X2fruitlet, 
Y2fruitlet). If the fruit coordinates are in the bbox coordinates 
of the bunches, it is concluded that the detected bunches are 
USB. The pseudo-code for determining a bunch is USB is as 
follows:

B. USB Counter based on centroid tracking 
An EFB is considered a USB in our USB counting system 
if it has at least one fruitlets. Hence the first step that is done 
is fruitlet detection and bunch detection. After the USB has 
been successfully detected, we use an object tracking method 
to determine whether the USB detected earlier is a new USB 
or the USB in the previous frame. The algorithm that we 
propose for  USB tracking is the centroid tracking algorithm. 
The object tracking algorithm works based on the Euclidean 
distance between the existing object’s centroid (i.e., the object 
that the centroid tracer has seen in the previous video frame) 
and the center of the new object between subsequent frames 
in the video as depicted in Fig. 10. 
 
 
Fig. 10. Two USB with its centroid and Euclidean Distance, 
Ct = Centroid, ED = euclidean distance 
 
The two centroids are compared, and if they exceed a 
certain threshold, then the USB that appears in this new frame 
is considered the new USB. It is done based on the assumption 
that the centroid of the same object in the old frame and the 
new frame do not differ much. The purpose of using the 
calculation method by utilizing object tracking is to reduce the 
double-counting of objects.

RCNN Faster-based USB counter system. The first test 
measures object detector capabilities to recognize trained 
labels (single fruitlets, double fruitlets, triple fruitlets, and 
bunch). The second test measures USB counter capabilities to 
detect and count USB in video streaming.

V. CONCLUSION 
Based on performance, we successfully proposed a deep 
learning-based USB detection and counter system using 
centroid tracking as part of the counter system with an average 
accuracy of 71.5%. This shows that the faster RCNN-based 
object detection system can be used as the backbone of the 
automatic counting system. The Euclidean-based tracking 
method can be used to avoid recounting objects that have been 
counted.
