Abstract— Automatic fruit yield counting in a real-world 
setting is an important challenge in crop management and fruit 
harvesting systems for increasing productivity at a low cost. 
Manual fruit counting for yield prediction for marketing and 
other administrative tasks takes time and requires additional 
human resources. This work uses image processing approach 
which reduces the labor-intensive task. Currently, varieties of 
techniques are available for automatic segmenting and 
counting of items in an image. The aim is in the direction of 
minimizing the manual counting process and automates the 
entire process that assist the farmers and wholesale dealers 
who are involved in fruit manufacturing process. It all starts 
with the recognition of fruits of various hues, which leads to the 
hybrid way of integrating texture and color aspects. For 
determining the ripeness stage of the fruit without viewing and 
checking for softness, a combination of color image 
segmentation and color detection technology has been utilized. 
The work utilizes the techniques for segmentation, detection 
and yield measurements of fruits. The suggested method will 
also function in different lighting circumstances, with occlusion 
of leaves and fruit overlapping on images collected from 
various distances from the trees.

AUTOMATED FRUIT COUNTING USING RANDOM 
FOREST ALGORITHM 
 
The Random Forest (RF) is one of the most effective 
classification and regression methods for classifying huge 
datasets. An ensemble of decision trees is generated by this 
algorithm. An arbitrary number of random forest trees are 
used to create the sample class. For classification, the RFs' 
predictions are assumed to be the majority votes of all tree 
forecasts, and for regression, all tree predictions are taken 
to be the average of all tree predictions.  
 
This application imports a dataset from the local storage 
with multiple fields where Time, Amount, v1 to v28 values, 
and class, are taken for further proceedings for the time 
being. The data for random forest model function are given 
by specifying the column names along with the name of the 
dataset. The random forest method is used to resample the 
data, which performs 10-folds and trains a Random Forest 
classifier using ROC. The reason for resampling is, if it is 
performed on a whole dataset and then made to split, the 
method would give some information into the testing set, 
thereby biasing the result in an optimistic way. Also, since 
the data set for the next interval is available, the result 
obtained using the prediction and the actual result can be 
cross verified and the accuracy can be measured. 
 
The input image is required to convert into gray color, and 
then Regional Maximum (RM), Distance Transform (DT) 
and area calculation are performed for automated counting. 
The center area of the fruit segment has the higher 
grayscale values. The total number of fruit count is obtained 
by the number of the RM of the input image. Next, the DT 
is performed but it requires the input image as binary form. 
After the converting into binary form, the pixels in 
segmentation have the value of 0 and the non-interested 
pixels have the value of 1. The nearest non-zero valued 
pixel between each pixel in the fruit region is calculated. 
The total area of the fruit in the image is then calculated. 
The relationship between the true count and database is 
analyzed using linear regression with the help of MATLAB 
programming.  
 
Based on the observation, the area method is suitable to 
check whether there is fruit in the image. The fruit count 
will be underestimated when many fruits are connected as 
one object by the DT method. While the regional maximum 
method will overestimate the fruit count due to too many 
local maxima. The error can be neutralized when both the 
overestimated and underestimated has occurred in one 
image. Later, the coordinates of edge pixels and the mean 
of pixels are found. Next, the center of the cluster is found 
by using the mean calculated and the approximated circle 
was fit into the data set. The local optimal accuracy of the 
algorithm is 95% based on the difference between manual 
counting and fruit count from the algorithm.
