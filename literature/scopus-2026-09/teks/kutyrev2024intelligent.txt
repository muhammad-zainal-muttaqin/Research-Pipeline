 
Intelligent crop yield prediction system using 
neural networks and databases  
Alexey Kutyrev1,* and Valeria Zubina1 
1Federal Scientific Agroengineering Center VIM, 1-st Institutsky proezd, 5, Moscow, 109428, Russia  
Abstract. Machine learning plays an important role in decision support and 
yield forecasting. This is an effective tool for determining strategies during 
the growing season of plants. The article proposes a method for predicting 
yield using a complex system consisting of a convolutional neural network 
(CNN), a feedforward neural network (FNN), and a SQLiteStudio database. 
The system includes several stages of data processing, starting with the 
collection and analysis of images and digital data obtained from various 
sources, and ending with yield forecasting based on this data. A 
convolutional neural network (CNN) is used to analyze images and video 
streams to recognize and count fruits on trees, providing accurate data about 
the status of the crop. Feedforward neural network (FNN) is used to analyze 
digital data, such as weather station data and long-term crop yield data, to 
subsequently predict crop yields. The received data is stored in a relational 
database, which ensures their structured storage and access for subsequent 
processing. Used SQL language to perform various database operations. To 
automate the process of counting fruits on trees, the YOLOv8 convolutional 
neural network model is used, which allows recognizing objects in real time. 
A Python script has been developed to process images using YOLOv8 and 
save the results to a database. An integrated system combines various 
methods and technologies to predict yields and automate data collection and 
analysis processes. The developed model showed a mean square error 
(MSE) of 7.33 and a mean absolute percentage error (MAPE) of 6.27%. 
1 Introduction 
The analysis of existing methods and algorithms for yield forecast showed that mathematical 
models (statistics, optimization, differential equations), probabilistic models (Bayesian 
methods, stochastic time series), information decision support systems (ISDS), fuzzy logic 
methods are currently used , regression models (linear regression, ridge regression, Lasso, 
polynomial regression), machine learning methods (random forest, gradient boosting, 
support vector machine), clustering methods (K-means, DBSCAN), neural networks 
(convolutional neural networks, recurrent neural networks RNN networks, deep neural 
networks, feedforward neural networks and hybrid methods (a combination of different 
methods) [1-6].

Modern database management systems (DBMS) are a set of language and software tools 
designed for creating, maintaining and sharing databases among many users. They provide 
access to the database in abstract terms that are not related to the way data is stored on the 
computer and have a built-in programming language that provides faster access to database 
resources. Modern DBMSs exist in several versions for various platforms. They provide 
effective tools for creating databases, maintaining database integrity, backup and recovery 
data [7,8].  
A DBMS can be used in various modes, such as a command mode, which provides a 
dialogue with the database at the level of syntactic structures of the DBMS language, and a 
program mode, which provides access to and management of data from application programs. 
Examples of modern DBMSs include MySQL, PostgreSQL, SQLite, Oracle, MongoDB, 
Microsoft SQL Server and Redis, and many others [9,10]. 
Requirements for such modern database management systems (DBMS) include: 1. 
Consistency of data, ensuring integrity and the impossibility of entering different values for 
one characteristic of an object. 2. Data recoverability to ensure safety in the event of hardware 
and software failures. 3. Data consistency, ensuring locking and consistency of information. 
4. High performance, scalability, reliability, maintainability and built-in tools for 
development and administration. 5. Relevance of stored data and ease of use for various 
categories of users. Currently, there are a large number of data models (structures). This is a 
representation of data and their interconnections (relationships) that describe the concepts of 
the problem environment. Data models are used to represent data structures at the conceptual 
and external levels (Fig. 1).

Thus, the DBMS used must have flexible logical record structures and open architectures 
to expand the capabilities and branches of record storage with the further need to develop an 
information retrieval system.

2 Materials and Methods 
As a result of the research, it was determined that the most suitable method for yield 
forecasting is to use a hybrid method based on the use of a convolutional neural network 
(CNN) and a feedforward neural network (FNN). This approach allows you to process 
heterogeneous data obtained from various sources as efficiently as possible. The stages of 
the complex system include data collection, image analysis, and data aggregation; yield 
forecasting, data updating, data visualization and report generation (Fig. 2). 
 
 
Fig. 2. Structure of an integrated yield forecasting system 
All received data is stored in a relational database, which provides structured storage and 
access for subsequent processing. A convolutional neural network (CNN) is used to analyze 
image and video streams obtained during ground monitoring. The model recognizes and 
counts fruits on trees, providing accurate data on the current status of the crop. A feedforward 
neural network (FNN) model is used to analyze digital data from weather stations, soil data, 
long-term crop data, and CNN data. FNN processes this data for subsequent yield prediction 
[11,12]. 
To develop the database, the SQL (Structured Query Language) language was used, 
intended for managing relational databases. Various operations such as creating and 
modifying database structure, inserting, updating, deleting and retrieving data were 
performed using SQL. The CREATE TABLE, ALTER TABLE, and DROP TABLE 
commands were used to create, modify, and drop tables. Data types and constraints for table 
columns including INTEGER, REAL and TEXT were also defined. The INSERT INTO 
command was used to add new rows to tables, the UPDATE command was used to modify 
existing data, and the SELECT command was used to extract data from tables. The 
SQLiteStudio database provides the ability to apply various conditions and filters using 
WHERE, JOIN, GROUP BY, ORDER BY and others. Data integrity constraints are defined, 
such as NOT NULL, CHECK, and PRIMARY KEY, as well as unique indexes to prevent 
duplicate data (for example, for a year) and to check the validity of values (for example, the 
range of soil pH values from 0 to 14 or the number of trees is not more than 1000 ). The 
SQLiteStudio graphical interface allows you to manage the database, create and edit tables, 
indexes, views and triggers to automatically perform specified actions when data changes, 
with the ability to save and integrate information into the json format for working in the 
Python programming language.  
To automate the process of counting the number of fruits on trees, a modern convolutional 
neural network model YOLOv8 (You Only Look Once, version 8) was used. The model 
allows you to recognize and classify objects in real time. The YOLOv8 architecture used is

divided into three main parts. The Backbone part is a convolutional neural network, which is 
responsible for extracting features from the input image. The backbone uses a modified 
version of the architecture CSPDarknet 53, which uses partial inter-stage connections to 
improve the information flow between different layers. The Neck part combines feature maps 
from different backbone stages to capture information at different scales. , which consists of 
several convolutional layers followed by a number of fully connected layers. These layers 
are responsible for predicting bounding boxes, objectness estimates, and class probabilities 
for objects detected in the image [13].  
Integrating YOLOv8 with a database for apple yield forecasting involves several steps, 
starting from image processing and ending with storing the data in the database. After 
training, the YOLOv8 model was used to analyze new tree images. YOLOv8 recognizes 
fruits in images by counting their number. After detection and counting of fruits, the data is 
saved into an SQL database. A script has been developed that checks for the presence of new 
images in a given folder, processes them using the YOLOv8 model and saves the results to 
the database. To develop the script, the task scheduler Task Scheduler (Windows) was used 
to automatically launch the script at certain intervals. The Python script runs automatically 
and performs the following actions: checks for the presence of new images in a given folder, 
processes the images using the YOLOv8 model, saves the fruit count results to the database. 
The architecture of a feedforward neural network (FNN) for predicting yield based on 
received data includes an input layer (Input Layer), fully connected layers (Fully-Connected 
Layers) and an output layer (Output Layer). The input layer corresponds to the features of 
the input data. Fully connected layers perform linear transformations using the ReLU 
activation function, except for the output layer, where the Softmax function is used to produce 
an interpretable result. FNN processes data from weather stations, soil data, long-term crop 
yield data, and convolutional neural network data for subsequent crop yield prediction.

 The developed Python script automates image processing and data storage using the

following function is defined, check_and_process_images(), which performs a series of steps 
to process images. Using the os.listdir() method, the script gets a list of files in the specified 
folder. For each file in the folder, the script checks whether it is a JPG image. If the file is an

The architecture of a feedforward neural network for predicting yield based on received 
data includes the following: an input layer (Input Layer), where each node corresponds to 
one feature or dimension of the input data; several Fully-Connected Layers, where each 
neuron is connected to each neuron of the previous and subsequent layers for linear data 
transformations. Each layer, except the output layer, uses a ReLU Activation function, and 
at the end of the neural network, a Softmax activation function is used to convert the neurons' 
output values into probabilities, providing an interpretable result. 
The feedforward neural network (FNN) architecture for apple yield prediction is designed 
to accommodate the need to process different types of data. During the development of FNN, 
hyperparameters were adjusted, such as the number of hidden layers, the number of neurons 
in each layer, and the learning rate. 
The FNN neural network consists of the following main components. In the Input Layer, 
each node represents one of the features of the input data. Traits may include temperature, 
humidity, rainfall, soil nutrient content and other indicators that affect yield. The input layer 
receives this data and passes it on to the next layer. Hidden Layers includes several layers, 
each of which consists of neurons connected to the neurons of the previous and next layers. 
These layers perform nonlinear transformations on the data, allowing the model to identify 
complex relationships between input traits and yield. The first hidden layer has 320 weights 
and 32 biases, the second hidden layer has 212 weights and 64 biases, the third hidden layer 
has 4160 weights and 64 biases, the fourth hidden layer has 8320 weights and 108 biases, the

fifth hidden layer has 129 weights and 1 bias. The ReLU (Rectified Linear Unit) activation 
function is used in these layers to introduce nonlinearity into the model, which improves the 
accuracy of predictions. The Output Layer consists of a single neuron that predicts the 
amount of harvest (in tons per hectare). The Softmax activation function is used to convert 
the output values of neurons into probabilities, which makes the result interpretable and 
convenient for further analysis. To train the feedforward neural network (FNN) model, the 
data was divided into training, validation and test sets in proportions of 70%, 15% and 15%, 
respectively. The training set was used to select model weights, the validation set to tune 
hyperparameters and prevent overfitting, and the test set to final evaluate performance. This 
approach ensured high accuracy of forecasts and stability of the model to new data. The 
model is trained using backpropagation and an optvimization algorithm such as Adam. This 
process involves minimizing a loss function that measures the discrepancy between predicted 
values and actual data. 
The developed model showed a mean square error (MSE) of 7.33 and a mean absolute 
percentage error (MAPE) of 6.27%. These metrics allow us to conclude about the accuracy 
of the model predictions, confirming its ability to make high-quality predictions with 
relatively low errors (Fig. 7).

to identify complex dependencies in the data.
