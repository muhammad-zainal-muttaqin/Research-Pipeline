Currently, palm-oil mills in Thailand employ staff to visually assess 
the ripeness of fresh palm bunches at point of purchase. This practice 
suffers from some limitations; the staff sometimes misjudges the ripe-
ness of fresh palm bunches. As a result, palm-oil mills have a higher 
than usual cost of purchasing palm bunches. The present research 
therefore aimed to develop a deep-learning model that can be used 
to analyze photographs of oil palm fresh fruit bunches and accurately 
classify their ripeness. The results showed that the ResNet50(C) model 
provided the best adjusted accuracy at 90%, where the F1 score of 
each category was noted to be higher than 80% ripeness. However, it 
is a large model and requires a longer average testing time (405 MB, 
2.48 seconds (GPU), 3.27 seconds (CPU)). If a smaller model size is de-
sired and a faster average testing time is needed, DenseNet121 (Train 
from Scratch) model can instead be considered. Although the model 
provided the adjusted accuracy at 86%, slightly less than that of the 
ResNet50(C) model, its F1 score for each class was as well above 80%; 
the model is smaller and requires a shorter average testing time (100 
MB, 1.76 seconds (GPU), 2.56 seconds (CPU)). The model is also highly 
robust to changes in the brightness of the photographs (range -70 to 
+70 from normal sunlight).

คุณลักษณะสĞำคัญของภาพถ่ายตามที่ผู้วิจัยได้กĞำหนดขึ้น จึง
ทĞำให้มีความยืดหยุ่นในการนĞำไปใช้งานตĞ่ำ กล่าวคือ ต้องมี
การกĞำหนดค่าของกล้อง เช่น ระดับแสงหรือมุมกล้อง หรือ
ต้องใช้เครื่องถ่ายภาพชนิดพิเศษ เพื่อให้ตัวแบบสามารถดึง
คุณลักษณะสĞำคัญของภาพถ่ายออกมาได้ตรงตามที่ตัวแบบ
ต้องการ ซึ่งโดยทั่วไปมักจะไม่มีความยืดหยุ่นในการนĞำไปใช้
งานจริง
2.2	Deep Learning
	
Deep Learning หรือ การเรียนรู้เชิงลึก เป็น
เทคนิคการวิเคราะห์ข้อมูลสมัยใหม่ซึ่งเริ่มเป็นที่นิยมอย่าง
แพร่หลาย หลังจากการเอาชนะการแข่งขัน ImageNet 
Large Scale Visual Recognition Challenge (ILSVRC) 
ในปี ค.ศ. 2012 ส่งผลให้การวิเคราะห์รูปภาพได้รับการ
พัฒนาอย่างต่อเนื่อง สิ่งสĞำคัญอย่างหนึ่งที่ทĞำให้ Deep 
Learning ให้ผลลัพธ์ที่เหนือกว่าเทคนิคการวิเคราะห์แบบ
ดั้งเดิมคือ เป็นเทคนิคที่มีการสร้างวิธีดึงคุณลักษณะสĞำคัญ
ของรูปภาพให้โดยอัตโนมัติ (Automatic Feature Extrac-
tion) ทĞำให้ตัวแบบสามารถเรียนรู้คุณลักษณะต่าง ๆ ของ
รูปภาพได้หลากหลาย ส่งผลให้ตัวแบบมีความยืดหยุ่นใน
การนĞำไปใช้งานจริงได้มากกว่าเทคนิคการวิเคราะห์แบบ
ดั้งเดิม สĞำหรับงานวิจัยที่เกี่ยวข้องกับการจĞำแนกประเภท
ความสุกของทะลายปาล์มสดโดยใช้ Deep Learning เริ่มต้น
ขึ้นในปี ค.ศ. 2018 จากงานวิจัยซึ่งใช้ Convolutional 
Neural Network (CNN) ด้วยตัวแบบประเภท Pre-trained 
CNN ได้แก่ AlexNet โดยใช้เทคนิคการเรียนรู้แบบ Trained 
from Scratch เปรียบเทียบกับตัวแบบซึ่งใช้เทคนิคการ
วิเคราะห์แบบดั้งเดิม ได้แก่ Support Vector Machines 
(SVM) โดยใช้ Histogram of Oriented Gradient (HOG), 
Fast Retina Keypoint (FAST) และ Color  Moment ใน
การทĞำ Feature Extraction พบว่าตัวแบบ AlexNet ให้
ผลลัพธ์ดีกว่าโดยให้ความถูกต้อง 100% ในขณะที่ใช้เวลา
เรียนรู้ไม่แตกต่างจากตัวแบบซึ่งใช้เทคนิคการวิเคราะห์แบบ
ดั้งเดิม [12] สอดคล้องกับงานวิจัยซึ่งใช้ Convolutional 
Neural Network (CNN) โดยใช้เทคนิคการเรียนรู้แบบ 
trained from scratch เท่านั้นในการจĞำแนกประเภทความ
สุกของทะลายปาล์มสดซึ่งให้ความถูกต้อง 98% [13] 
นอกจากนี้ ยังมีงานวิจัยเปรียบเทียบระหว่าง Pre-trained 
CNN ประเภทต่าง ๆ ได้แก่ การเปรียบเทียบระหว่าง 1) 
AlexNet 2) DenseNet+SE layer 3) ResAtt DenseNet 
และ 4) DenseNet Sigmoid พบว่า ResAtt DenseNet ให้
ผลลัพธ์ดีกว่าโดยมี F1 score 69.29% [14] การเปรียบเทียบ
ระหว่าง AlexNet กับ DenseNet พบว่า DenseNet ให้
ผลลัพธ์ดีกว่าโดยให้ความถูกต้อง 86% [15]
จากงานวิจัยข้างต้น แม้จะให้ผลลัพธ์ที่น่าพอใจ แต่ยังมี
ข้อจĞำกัดเนื่องจากมีการใช้ภาพถ่ายต่อประเภทความสุก
จĞำนวนน้อยจĞำนวนภาพถ่ายของแต่ละประเภทมีความแตก
ต่างกันมาก เช่น ใช้ภาพปาล์มดิบเพียง 8 ภาพ และปาล์ม
กĞำลังสุก 16 ภาพ ในขณะที่ใช้ปาล์มสุกเต็มที่ 168 ภาพ โดย
ไม่มีการทĞำ Data Augmentation รวมถึงการแบ่งประเภท
ความสุกมีจĞำนวนแตกต่างกัน โดยบางงานวิจัยมีการแบ่ง
ประเภทความสุกในจĞำนวนที่ตĞ่ำเกินไป เช่น แบ่งเป็นประเภท
สุกและดิบเท่านั้น (รายละเอียดแสดงในตารางที่ 2) นอกจากนี้ 
การพัฒนาสายพันธุ์ปาล์มของแต่ละประเทศมีความแตกต่าง
กัน ทĞำให้ผลลัพธ์ของแต่ละงานวิจัยอาจมีความคลาดเคลื่อน 
และอาจไม่สามารถนĞำตัวแบบดังกล่าวมาใช้งานใประเทศไทย
ได้จริง

3.1 ลักษณะของข้อมูล
	
ข้อมูลที่ใช้ในการศึกษา คือ ชุดของภาพถ่ายทะลาย
ปาล์มซึ่งเกษตรกรได้ตัดออกจากต้นปาล์มและนĞำมาส่งให้
โรงงานสกัดนĞ้ำมันปาล์ม โดยสามารถแบ่งประเภทของ
ภาพถ่ายได้จากระดับความสุกของทะลายปาล์มทั้งทะลาย
ตามเกณฑ์ของโรงงานสกัดนĞ้ำมันปาล์มตามจริง ได้แก่ 1) 
ทะลายปาล์มดิบ (Unripe bunch) 2) ทะลายปาล์มกĞำลังสุก 
(Underripe bunch) 3) ทะลายปาล์มสุกเต็มที่ (Fully ripe 
bunch) และ 4) ทะลายปาล์มสุกมากเกินไป (Overripe 
bunch) เป็นต้น ข้อมูลดังกล่าวไม่ได้แบ่งแยกตามสายพันธุ์
ปาล์ม สอดคล้องกับกระบวนการรับซื้อของโรงงานตามปกติ
จะไม่มีการรับซื้อทะลายปาล์มแยกตามสายพันธุ์เช่นเดียวกัน 
เนื่องจากสายพันธุ์ปาล์มที่ใช้ปลูกเพื่อการพาณิชย์ส่วนใหญ่
อยู่ในตระกูลเดียวกันคือ สายพันธุ์เทเนอรา (TENERA) จึงมี
ลักษณะคล้ายกัน ยกเว้นสายพันธุ์ปาล์มสุราษฎร์ธานี 1 ซึ่งมี
ลักษณะของสีและลักษณะพื้นผิวแตกต่างจากสายพันธุ์ 
อื่น แต่พอรับได้เนื่องจากเป็นสายพันธุ์ที่พบได้น้อยใน
ประเทศไทย ดังนั้นงานวิจัยนี้จึงไม่ได้รวบรวบภาพถ่ายทะลาย
ปาล์มสายพันธุ์ดังกล่าวไว้ในชุดข้อมูล โดยลักษณะของ
ภาพถ่าย 1 ภาพ จะประกอบด้วยภาพทะลายปาล์มเต็มใบ 
1 ทะลาย ซึ่งสะท้อนคุณลักษณะของสี (Color) และลักษณะ
พื้นผิว (Texture) แต่ไม่ได้สะท้อนถึงจĞำนวนผลที่ร่วง 
บริเวณรอบ ๆ ทะลาย หรือจĞำนวนผลที่หลุดออกจากทะลาย 
เนื่องจากผู้รวบรวมมีข้อจĞำกัดไม่สามารถระบุได้ชัดว่าผลร่วง
รอบ ๆ นั้นเป็นของทะลายปาล์มใด และทะลายปาล์มมี 
นĞ้ำหนักค่อนข้างมาก ผู้รวบรวมจึงไม่สามารถยกทะลายปาล์ม
เพื่อพิจารณาจĞำนวนผลที่หลุดร่วงได้ ซึ่งเป็นข้อจĞำกัดเดียวกัน
ของพนักงานผู้ประเมินเช่นเดียวกัน นอกจากนี้ ภาพถ่าย 
ดังกล่าวจะไม่มีการควบคุมลักษณะของพื้นหลังของทะลาย
ปาล์มแต่อย่างใด เพื่อสร้างตัวแบบที่สามารถจĞำแนกทะลาย
ปาล์มได้โดยไม่ขึ้นอยู่กับพื้นหลัง ตัวอย่างตามรูปที่ 2

3.5 การประเมินผลลัพธ์
	
3.5.1 Confusion Matrix 
	
ประเมินผลลัพธ์ของตัวแบบด้วย Confusion Ma-
trix ซึ่งเหมาะสมกับตัวแบบการจĞำแนกประเภท (Classifica-
tion model) โดยทดสอบกับ Validation set และ Test 
set โดยมีตัวชี้วัดประสิทธิภาพที่สามารถคĞำนวณได้จาก 
Confusion Matrix ได้แก่ Accuracy, Precision, Recall 
และ F1 score ซึ่งสามารถแสดงการคĞำนวณได้ ดังนี้
โดยที่	
TP (True Positive) คือ จĞำนวนข้อมูลที่เป็น Class i 
และถูกตัวแบบจĞำแนกว่าเป็น Class i
FP (False Positive) คือ จĞำนวนข้อมูลที่ไม่ใช่ Class 
i แต่ถูกตัวแบบจĞำแนกว่าเป็น Class i
TN (True Negative) คือ จĞำนวนข้อมูลที่ไม่ใช่ Class 
i และถูกตัวแบบจĞำแนกว่าไม่ใช่ Class i
FN (False Negative) คือ จĞำนวนข้อมูลที่เป็น Class 
i แต่ถูกตัวแบบจĞำแนกว่าไม่ใช่ Class i
โดยที่ i คือ 1, 2, 3 และ 4
(1) ค่าความถูกต้อง (Accuracy) คือ ความถูกต้องใน
การจĞำแนกข้อมูลของทั้งตัวแบบ
(2) ค่าความแม่นยĞำ (Precision) คือ ความแม่นยĞำใน
การจĞำแนกข้อมูลว่าเป็น Class i ได้ถูกต้องเทียบกับข้อมูล
ทั้งหมดที่จĞำแนกเป็น Class i
(3) ค่าความระลึก (Recall) คือ ความสามารถของตัว
แบบในการจĞำแนกข้อมูลที่เป็น Class i เมื่อเทียบกับข้อมูลที่
เป็น Class i ทั้งหมด
(4) ค่าความถ่วงดุล (F1 score) หรือ ค่าเฉลี่ยฮาร์มอ
นิกของตัวชี้วัดค่าความแม่นยĞำและค่าความระลึก คือ ตัวชี้วัด
ที่คĞำนวณจากค่า Precision และ Recall เพื่อให้สามารถวัด
ค่าทั้งสองได้พร้อมกันด้วยตัวชี้วัดเดียว
สĞำหรับงานวิจัยนี้ เลือกพิจารณาค่าความถูกต้อง (Ac-
curacy) เพื่อชี้วัดความถูกต้องของตัวแบบโดยรวม และ
พิจารณา F1 score กรณีพิจารณาความถูกต้องของแต่ละ 
Class เนื่องจากต้องการตัวแบบซึ่งสามารถจĞำแนกความสุก
ของทะลายปาล์มได้ถูกต้องทุก Class ทั้งในมุมของค่าความ
แม่นยĞำ (Precision) และค่าความระลึก (Recall) ซึ่งจะสร้าง
ความสมดุลทั้งในมุมของผู้ซื้อและผู้ขาย
สĞำหรับ Adjusted accuracy คือ ค่าความถูกต้อง (Ac-
curacy) ที่สะท้อนว่าตัวแบบสามารถจĞำแนกข้อมูลทดสอบ
ได้ถูกต้องเป็นจĞำนวนเท่าใดเมื่อเปรียบเทียบกับจĞำนวนข้อมูล
ทดสอบทั้งหมด โดยข้อมูลทดสอบที่จĞำแนกได้ถูกต้อง จะ
หมายถึง ข้อมูลที่ตัวแบบสามารถจĞำแนกตาม Class ที่ระบุ
ไว้ได้ถูกต้อง และเป็นข้อมูลที่ตัวแบบได้พิจารณาจากบริเวณ
ทะลายปาล์มที่ถูกต้องจาก Heatmap ของ Grad-CAM

มีขนาดเล็กลงและใช้เวลาเฉลี่ยในการทดสอบได้เร็วขึ้น (100

การจĞำแนกความสุกของทะลายปาล์ม ณ จุดรับซื้อ และ 2)

ความสว่างของภาพถ่าย (Brightness) ได้ดีสĞำหรับกรณีที่

• การระบุประเภทความสุกของทะลายปาล์มโดยการวัด
ระดับเปอร์เซ็นต์นĞ้ำมันปาล์มที่ได้จริงตามกระบวนการทาง
