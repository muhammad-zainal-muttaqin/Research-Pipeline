Abstract—Classification of fruits is an onerous and 
tedious task because of countless number of fruits. 
The 
traditional 
approach 
for 
detection 
and 
classification of fruit and its maturity level is based on 
the naked eye observation by the experts, which is 
both time consuming and causes eye fatigue. Advance 
techniques in image processing and machine learning 
helps to automatic classify and count the fruits, 
accurately, quickly and non-destructively. A method 
to automatic detect and classify apple fruit maturity 
level, whether it is mature or immature based on its 
color features has been proposed. Images of the apple 
are resized and Image Processing Techniques are 
applied for the extraction of apple color components 
(R, G, B). Artificial Neural Network is used as a 
classifier to identify and count the mature and 
immature 
applesusingcolor 
components. 
The 
proposed model has an accuracy of 98.1%, when all 
the three attributes are used as an input.

Feed Forward Neural Network.

INTRODUCTION 
 
India is the second largest fruit producing country 
in the world after China. With the advancement in 
technology, a new generation of agricultural 
techniques promises to take more of the toil out of 
farming by automating the business of growing 
fruit. Farmers growing crops such as apples, 
oranges, strawberries etc. needs to be handpicked 
which is very time consuming, costly and causes 
eye fatigue. As said by Tony Stentz of the Robotics 
Institute 
at 
Carnegie 
Mellon 
University 
in 
Pittsburgh –“It is actually not hard to pick an 
orange, but it is very hard to pick an orange cost 
effectively”[1][1]. Automation is not only cost 
effective but it also increases the accuracy. 
Classification of fruits is an onerous and tedious 
task because of countlessnumber of fruits. The 
traditional 
approach 
for 
the 
detection 
and 
classification of fruit and its maturity level is based 
on the naked eye observation by the experts. In 
 
developing countries like India, consulting experts are 
expensive and time consuming due to the distant

variability are serious concerns for apple. Apple crop 
accounts for about 2.8% of the total fruit production of 
the country and ranks sixth in production[2].To the

adopted approach[6]. 
 
Neural network emulates the human brain and

eye. The normal human eyes have mainly three 
types of sensors and these three sensorெs signals 
determine the color response of the observer. RGB

which are red, green and blue. A color image has a 
range of intensity from 0 to 255 for each color 
component and when these three are combined 
 
various intensities are superimposed to obtain a 
colorized hue[3].

III. 
EXISTING WORK 
 
A simple color recognition algorithm is proposed to 
determine the ripeness of the banana fruit using 
neural network [13]. Web digital camera is used to 
capture the RGB images of the bananas each image 
resolution being 320× 240 pixels. Four sets of 
bananas are used for identifying the ripeness of the 
fruit each having different size and ripeness.10-14 
pieces of bananas is contained in each set. All the 
banana images are captured in four different 
positions daily until each of the bananas become 
rotten. 
 
It has mainly three steps: preprocessing, feature 
extraction 
and 
ripeness 
classification. 
In 
preprocessing images are resized and RGB 
components are extracted. Histogram are used as a 
feature vector in feature color extraction after the 
rescaling of the images using simple heuristic 
method. This method used supervised Neural 
Network technique by utilizing the error back 
propagation model having output layer of 9 input 
neurons, 45 hidden neurons and one output layer 
with one output neuron. Identification accuracy 
achieved is96%.

V. 
MODEL DESCRIPTION 
 
A. Image pre-processing 
 
Image pre-processing is a technique in which 
resizing and rescaling of the images are performed. 
 
B. Feature Extraction 
 
The raw images are first collected in a database 
known as Raw ImagePrimary Database and then 
segmentation techniques are applied on each of the 
images to extract their features such as color(R, G, B). 
The attributes extracted are collected in another 
database known as Primary Database, in other words, 
it is also called a feature space. These data are called 
the Training Data. In a similar way, if any query 
image arrives from the customerெs side then all the 
query images is stored in a database known as Raw 
Image Query Database. Againsegmentation 
techniques are applied similar to the above-
mentioned ways and the extracted attributes are 
saved in another database known as Query 
Database.These data are known as Test Data. 
 
C. Training 
 
Training a network refers to forming the structure 
for a particular application. Initial weights are 
chosen randomly and so is the Data Division 
(dividend). Scaled Conjugate Gradient (training 
function) algorithm is used for training the neural 
network model. SCG is good for both function 
approximation as well as pattern recognition and 
training is the best function among all. 
 
D. Testing 
 
This is a common concept in machine learning in 
which the test image data can be compared with the 
training image data to get the classification result. 
 
E. Fruit Classification 
 
Machine learning is used for the pattern recognition 
and counting purpose. There are various types of 
classifiers which can effectively and efficiently 
classify the mature and immature fruits. In this 
paper, we are going to use two layers Feed-Forward 
Back-propagation Artificial Neural Network with 
tan sigmoid in both hidden and output layer to 
classify the fruits. In ANN trained and testing data 
are used to help the classifier to produce the output. 
The trained data are used to train the model and the 
test data are used to find whether the given fruit can 
be classified as mature or immature the trained 
model. In this way classification as well as counting 
is performed using both the classifiers. 
 
F. Algorithm 
 
Steps involved in experimentation are: 
 
Step 1: 150 images as an input forming a database 
and each image belonging to any of the two 
categories i.e. mature or immature. Rescaling of the 
image is done. 
 
Step 2: Three features are extracted from each 
image i.e. 3 color feature (R, G,B). 
 
Step 3: The feature matrix obtained in step 2 and 
the target matrix are normalized so that the value 
lies between 0 and 1. 
 
Step 4: The normalized data-set are then divided 
into training and testing dataset. (Random division 
in ANN) 
 
Step 5: The classifier is used to train and create the 
model using the training dataset. 
 
Step 6: To analyze the performance of the classifier 
and calculate the confusion matrix test data-set is 
used. The output is given by the classifier if it is 
acceptable, else return to step 5 for re-training the 
model.

VII. 
CONCLUSION 
 
Here, we developed a method for the automatic 
recognition and counting of mature and immature 
apple fruits from images. The method follows three 
main steps, they are: preprocessing, feature extraction 
and 
maturity 
classification. 
The 
work 
was 
accomplished by training a set of input data. After 
preprocessing, the feature extraction stage is applied to 
each resized captured images. The feature space is 
created using the extracted attributes. A Neural 
Network model is developed for color recognition. 
From the experimental results, the simulations show 
that the accuracy for the maturity level is 98.1%. For 
future research, shape and texture attributes can be 
added in the feature space and instead of a single fruit; 
a bunch of fruits or on-plant fruits can be taken into 
consideration to increase the accuracy and efficiency 
of the model. This method can be used by the farmers 
to evaluate the exact harvesting time of the fruit and 
necessary precautionary actions can be taken to 
protect the fruit from various diseases in future. This 
in turn will increase the yield of the apple fruit.
